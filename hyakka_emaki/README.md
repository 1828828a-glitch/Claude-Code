# 百花繚乱絵巻

来場者がスマホから草花を描き、大画面の庭に芽吹かせるインタラクティブ作品。
[インタラクティブ百鬼夜行絵巻](https://x.com/ka0ru_1620/status/2081283014156517791) の園芸版として作った。

| 元ネタ（百鬼夜行） | この作品（百花繚乱） |
| --- | --- |
| 妖怪キャラ | 草花 |
| 水墨風に変換 | 琳派・花鳥画風（墨線＋岩絵具＋和紙）に変換 |
| 画面を練り歩く | 地面から芽吹き、育ち、風に揺れ続ける |
| 百鬼夜行絵巻 | 横スクロールする和紙の庭絵巻 |

## 流れ

1. 大画面（`/`）にQRコードが出ている
2. 来場者がスマホで読む → 投稿画面（`/m`）
3. 指で草花を描く、または写真を撮る
4. 植物名と説明を書いて「庭に植える」
5. 変換された草花が大画面の庭に芽吹き、立札に名前と一文が縦書きで立つ
6. 立札が引くと、その株は庭の一員として揺れ続ける

株が `HANA_MAX_PLANTS`（既定60）を超えると、古い株から枯れて土に還る。

## 動かす

```bash
pip install -r requirements.txt
./run.sh
```

起動すると大画面・スマホ・管理用のURLがコンソールに出る。

会場では、大画面を置く端末のLAN内IPを渡しておくとQRがそこを指す。

```bash
HANA_PUBLIC_URL=http://192.168.1.20:8000 HANA_PORT=8000 ./run.sh
```

同じLANにいるスマホからQRを読めば、そのまま参加できる。

### 設定

| 環境変数 | 既定 | 何を決めるか |
| --- | --- | --- |
| `HANA_PUBLIC_URL` | （空） | QRコードが指すURL。空ならブラウザのオリジンを使う |
| `HANA_HOST` / `HANA_PORT` | `0.0.0.0` / `8000` | 待ち受け |
| `HANA_MAX_PLANTS` | `60` | 庭に同時に生やす株の上限 |
| `HANA_SUBMIT_COOLDOWN` | `8` | 同じ端末が続けて投稿できるまでの秒数 |
| `HANA_MAX_UPLOAD_BYTES` | `12MB` | アップロード画像の上限 |
| `HANA_DATA_DIR` | `./data` | 庭の保存先（`garden.json` とスプライト） |
| `ANTHROPIC_API_KEY` | （空） | 設定すると立札の文章をClaudeが書く |
| `HANA_LABEL_MODEL` | `claude-opus-5` | 立札に使うモデル |

庭を更地に戻すURLは起動時にコンソールへ出る（合言葉つき）。合言葉は起動ごとに変わる。

## 中身

```
server/
  main.py      画面配信・投稿API・WebSocket
  stylize.py   画像 → 草花スプライトへの変換
  store.py     庭の状態、間引き、永続化、配信
  labeler.py   立札の文章（Claude または手元生成）
  config.py    設定
static/
  display.*    大画面（canvas、和紙の庭、成長と揺れ、縦書きの立札）
  mobile.*     スマホ（ペイント、写真、投稿）
```

### 画像の変換について

元ネタは生成AIで水墨風の動くキャラに変換しているが、**ここでの絵の変換は生成モデルではなく決定論的な画像処理**（`stylize.py`）で行っている。

1. 被写体の切り抜き（ペイントは透過、写真は背景色からの距離と彩度で推定）
2. メディアンフィルタで塗り面をまとめる
3. 岩絵具パレットへ寄せて明度を段階化する
4. DoGとシルエットから墨線を起こし、にじみとかすれを乗せる
5. 隈取り・岩絵具のムラ・和紙の粒子を重ねる
6. 根元の位置と代表色を算出して透過PNGで返す

APIキーも学習済みモデルも要らず、1枚あたり0.3秒ほどで完結する。生成モデルに差し替えたい場合は `stylize()` を同じ `Sprite`（RGBA画像・`root_x`・`bloom_color`）を返す実装に置き換えればよい。

「動く」部分は変換後にクライアント側で作っている。スプライトを横スライスに切り、根元からの高さに応じて位相をずらして揺らすことで、草花らしいしなりが出る。

### 立札の文章

`ANTHROPIC_API_KEY` があれば Claude が20〜40字の一文を書く。株は先にローカル生成の文言で庭へ出し、Claudeの文が届いたら `relabel` で差し替えるので、APIの遅延で登場が待たされることはない。キーがなければローカル生成のまま動く。

## 確認済み

ローカルで一通り通してある。

- スマホで描く → 変換 → 大画面に芽吹く → 縦書きの立札 → 揺れ続ける
- 写真からの投稿と背景切り抜き
- 上限超過による間引き（スプライトも削除される）
- プロセスを落として `garden.json` から庭を復元
- 連投のクールダウン（429）、画像でないデータ（400）、合言葉違いの更地化（403）

立札のClaude生成だけはAPIキーがない環境のため未実行。SDKの呼び出し形（`messages.create` の引数、`AsyncAnthropic.close`）は実物に照らして確認してある。

crack リール動画（田中さんの話）

out/crack_reel.mp4 がそのまま Instagram リールに上げられる完成版です。1080x1920、30fps、H.264。音は無音のトラックだけ入れてあるので、投稿するときにアプリ内の音源からピアノかアンビエント系を重ねてください。out/cover.png はカバー画像の候補です。

絵は index.html の中で全部描いています。ブラウザで開くとそのまま再生されるので、文言やタイミングを変えたいときは index.html の ITEMS を書き換えて確認し、満足したら書き出し直します。dur がその文が画面に出ている秒数です。

書き出し直す手順

    ./fetch_fonts.sh      # 初回だけ。明朝体などを fonts/ に落とす
    node render.mjs       # out/crack_reel.mp4 を作り直す
    node render.mjs --stills 12,54.5   # 指定秒のフレームを PNG で確認

Playwright（Node 版）と ffmpeg が要ります。

文字はリールの上の見出し、下のキャプション、右のボタンにかからない範囲に収めています。ロゴは書体で組んだ仮のものなので、正式なロゴ画像があれば ITEMS の最後のカードを差し替えてください。

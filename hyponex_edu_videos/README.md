# ハイポネックス 園芸の基本編 縦型動画

園芸に詳しくない人に向けた解説動画4本を、Canvas と JavaScript だけで描画して MP4 に書き出すプロジェクトです。企画シートの構成、演出、テロップ、注意点の列をもとに作っています。

| 番号 | タイトル | 長さ | 出力ファイル |
| --- | --- | --- | --- |
| 1 | 肥料とは？植物に肥料は必要なの？ | 70秒 | out/01_肥料とは_植物に肥料は必要なの.mp4 |
| 2 | 活力剤とは？肥料との違いは？ | 62秒 | out/02_活力剤とは_肥料との違いは.mp4 |
| 3 | 肥料の「元肥（もとごえ）」とは？ | 66秒 | out/03_肥料の元肥とは.mp4 |
| 4 | 肥料の袋にある「N-P-K」って何？ | 80.5秒 | out/04_肥料の袋にあるNPKって何.mp4 |

仕様は 1080×1920、30fps、H.264（High, yuv420p, BT.709）、AAC 48kHz ステレオ。音量はおよそ -16 LUFS にそろえています。

## 作りの考え方

ナレーション音声は入れていません。SNS は音なしで流れることが多く、イベント会場のサイネージも無音の場合があるので、台本のセリフはすべて字幕で出し、要点は大きな見出しテロップで重ねています。音声を後から収録する場合も、字幕の表示時間がそのまま読み上げの目安になります。

画面の上端と下端は各SNSのボタンや説明文に隠れやすいので、見せたい情報は上から170〜1500pxの範囲に収めました。最下部の緑の帯には番組名とタイトルを置いています。ここはSNSでは隠れても困らず、サイネージでは何の動画かが分かる場所です。

注意書きは注意点の列に沿って入れています。#1 は「※肥料のあげすぎには注意してね！」、#4 は「※植物の種類や生育時期によって必要なバランスは異なります」です。

## 使い方

Node.js 22 以降が必要です。

```bash
npm install
npm run render            # 4本すべて書き出し（out/ に MP4）
npm run render -- v2      # 1本だけ
npm run render -- v1 --preview --from=40 --to=50   # 一部分だけ軽く確認
npm run preview           # http://127.0.0.1:8765/player.html でプレビュー再生
```

書き出しは Playwright の Chromium で1フレームずつ描画し、生の画素を ffmpeg に渡しています。Chromium が入っていない場合は `npx playwright-core install chromium` で入れてください。場所は環境変数 CHROMIUM_PATH でも指定できます。ffmpeg は npm の @ffmpeg-installer から自動で入り、FFMPEG_PATH で別のものに替えられます。手元の環境では1本あたり1分半ほどで書き出せました。

確認用の静止画は `node tools/stills.mjs v1 1.5,10,30` のように秒数を渡すと out/stills に並べて保存されます。

## セリフやタイミングの直し方

src/videos/v1.js〜v4.js が各動画の台本です。場面ごとに次の要素があります。

- start は場面の開始秒
- subs は字幕で、[開始秒, 終了秒, 文字] を場面内の時間で書く。`*強調*` で色が変わり、`\n` で改行
- telops は大きな見出しテロップ。`{元肥|もとごえ}` と書くとふりがなが付く
- cues は効果音のタイミング（pop, chime, buzzer, sparkle など。一覧は src/audio/synth.js の SE）
- note は画面下の小さな注意書き

字幕が1秒あたり7.5文字を超えると、書き出し時に警告が出ます。

## ファイル構成

- src/engine … 描画の土台（イージング、テキスト、字幕、場面転換、ヘッダー）
- src/art … キャラクター、植物、小物、背景のイラスト（すべてコードで描画）
- src/audio/synth.js … BGM（ウクレレ、マリンバ、ベース、リズム）と効果音の合成
- src/videos … 4本の台本とタイムライン
- assets/source … 受け取った素材（ロゴ、商品写真）
- assets/cutout … 背景を透過した素材
- tools … 背景透過、書き出し、静止画確認、プレビュー用サーバー

## 素材の背景透過

商品写真は BiRefNet（MIT ライセンス）を transformers.js で動かして切り抜き、白背景のにじみを色の計算で取り除いています。ロゴは平面的な図形なので、白地を色で判定して透過し、P・O・e の文字の穴も抜いています。作り直すときは `npm run cutout` を実行してください。初回はモデルを約1GBダウンロードします。onnxruntime-node のインストールでGPU用ファイルの取得に失敗する環境では、`ONNXRUNTIME_NODE_INSTALL_CUDA=skip npm install` で入れ直せます。

マグァンプKの写真は袋の下端が画像の外で切れているため、画面では台座の手前の縁で下端を隠しています。リキダス顆粒の画像も切り抜き済みですが、台本に登場しないので今回の動画では使っていません。

## 翻訳版を作るとき

文字はすべて src/videos のファイルに入っているので、差し替えれば多言語版を作れます。注意点の列にあるとおり、海外ではパッケージが異なることがあるため、assets/source の商品画像は現地のものに替えてください。焼肉やお弁当などのたとえも、国に合わせた言い換えを検討してください。

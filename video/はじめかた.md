# はじめかた（プログラミング未経験の方向け）

このフォルダは「台本を渡すと、アニメーション動画ができる工場」です。
ここでは、あなたのパソコンでこの工場を動かして、
**絵付きの動画を1本作るまで**を順番に説明します。

コードを書く必要はありません。やることは
「黒い画面（ターミナル）に、書いてある通りの文字を貼り付けてEnterを押す」だけです。

---

## 0. 全体像（何をするのか）

1. 道具を入れる（Node.js）……最初の1回だけ
2. この材料一式を自分のパソコンに持ってくる……最初の1回だけ
3. OpenAIの「APIキー」を用意する……最初の1回だけ
4. 絵・声・地図・効果音を自動生成する
5. 動画（mp4）を書き出す

初回はぜんぶで30分くらい。2回目からは4と5だけなので数分です。

---

## 1. 道具を入れる（最初の1回だけ）

### ターミナルを開く

- **Mac**: 「アプリケーション → ユーティリティ → ターミナル」
  （または Cmd+スペース で「ターミナル」と検索）
- **Windows**: スタートメニューで「PowerShell」と検索して開く

黒い（or 白い）文字だけの画面が出ます。ここに命令を貼り付けて Enter を押すと
パソコンが実行してくれます。**この後の手順は全部この画面でやります。**

### Node.js を入れる

動画工場を動かすエンジンです。

1. https://nodejs.org を開く
2. 「LTS」と書いてある方の緑のボタンを押してダウンロード
3. ダウンロードしたファイルを開いて、「次へ」を押していくだけでOK

入ったか確認します。ターミナルに貼り付けて Enter:

```
node --version
```

`v20.11.0` のような数字が出れば成功です。
（`command not found` と出たら、ターミナルを一度閉じて開き直してみてください）

---

## 2. 材料一式を持ってくる（最初の1回だけ）

ターミナルに1行ずつ貼り付けて Enter を押します。

```
git clone https://github.com/1828828a-glitch/Claude-Code.git
```

```
cd Claude-Code/video
```

```
npm install
```

- 1行目: 材料一式を GitHub からコピーしてくる
- 2行目: その中の video フォルダに移動する
- 3行目: 必要な部品を自動で揃える（1〜2分かかります）

> **`git` が無いと言われたら**: Mac は `xcode-select --install` を実行、
> Windows は https://git-scm.com からインストールしてください。

以降、ターミナルを開き直したときは `cd Claude-Code/video` だけやり直せばOKです。

---

## 3. OpenAI の APIキーを用意する（最初の1回だけ）

絵と声の生成には OpenAI のサービスを使います。そのための「合鍵」がAPIキーです。

1. https://platform.openai.com にアクセスしてアカウントを作る
   （ChatGPT のアカウントとは**別物**です。ChatGPT Plus に入っていても、
   こちらは別に課金設定が必要です）
2. 画面の指示に従って支払い方法を登録し、**$5〜10 くらいチャージ**する
3. 左のメニューから「API keys」→「Create new secret key」
4. `sk-` で始まる長い文字列が出るので、**その場でコピーしてメモ帳などに保存**
   （この画面を閉じると二度と表示されません。消えたら作り直せば大丈夫です）

### お金の目安

- 絵1枚 …… 約10円
- 声1カット …… 約1〜2円
- サンプル動画1本まるごと …… **100円しないくらい**

一度作った絵と声は保存されて使い回されるので、
**同じ命令を何度実行しても二重に課金されません。**

### キーの扱い（大事）

APIキーは**クレジットカード番号と同じ扱い**にしてください。

- チャットやSNSに貼らない
- 誰かに送らない
- 使い終わったら OpenAI の画面から削除（Revoke）してもいい。また作ればいいだけです

### キーをターミナルに教える

ターミナルに貼り付けます。`sk-あなたのキー` の部分を実物に置き換えてください。

- **Mac**:
  ```
  export OPENAI_API_KEY=sk-あなたのキー
  ```
- **Windows (PowerShell)**:
  ```
  $env:OPENAI_API_KEY = "sk-あなたのキー"
  ```

何も表示されなければ成功です。
**ターミナルを閉じると忘れられる**ので、次回はまたこの1行から始めてください。

## 3.5 APIキーを作りたくない場合（ChatGPT Plus で代用する）

「ChatGPT Plus に入っているのに、また別でお金を払うの？」と思った方へ。

残念ながら **Plus の契約でこのツールの自動生成は動きません**。
ChatGPT（月額の会員サービス）と API（プログラムから使う従量課金サービス）は、
同じ会社の**別々の契約**だからです。スマホの「かけ放題プラン」に入っていても
公衆電話はコインが要る、というのに近い関係です。

ただし、**手作業でよければ Plus の画像生成をそのまま使えます**。

1. まず、作る予定の絵の指示文一覧を出します（無料）:
   ```
   npm run assets -- src/scripts/history-honnoji.json --dry-run
   ```
2. 出てきた指示文を1つコピーして、**ChatGPT の画面**に貼り付けて画像を作らせる
3. できた画像をダウンロードして、`public/photos/` フォルダに入れる
   （名前は自由。例: `honnoji-room.png`）
4. 台本（`src/scripts/history-honnoji.json`）の該当シーンに1行足す:
   ```
   "image": "photos/honnoji-room.png"
   ```
5. これを絵が欲しいカットの数だけ繰り返す

手動で置いた絵は、あとで `npm run assets` を実行しても**上書きされません**。
「よく使うカットは手動、量産はAPI」という併用もできます。

| | ChatGPT Plus（手作業） | API（自動） |
|---|---|---|
| 追加費用 | なし（Plus の範囲内） | 絵1枚 約10円 |
| 手間 | 1枚ずつコピペ・保存・記入 | コマンド1回で全部 |
| キャラの顔を揃える | ChatGPT の同じ会話内で「同じ人物で」と頼む | 自動（参照画像を機械が渡す） |
| 向いている人 | まず数本試したい | 量産したい |

**まず Plus の手作業で1本作ってみて、続けられそうなら API に移る**のが
一番無駄がありません。

### ナレーションも「別で作って渡す」ことができます

声もAPIなしで用意できます。作り方は好きなもので構いません:

- **VOICEVOX**（無料の読み上げソフト。https://voicevox.hiroshiba.jp ）
- スマホやPCでの**自分の声の録音**
- その他の読み上げサービス

読み上げる文は `npm run voice -- <台本> --dry-run` で一覧が出ます。
カットごとに1ファイルずつ作り、**ファイル名をカット番号で始めて**
（`01.wav` `02.mp3` `05-タイトル.m4a` など）1つのフォルダに入れ:

```
npm run voice-import -- src/scripts/hibiya-kadan.json 音声フォルダ
```

これで各カットに音声が割り当てられ、**カットの長さも音声の実測値に
自動で合います**。手動で入れた音声は `npm run voice` に上書きされません。

## 4. 素材を自動生成する

サンプルとして「本能寺の変」の解説動画（約1分）の台本が入っています。
これに絵・声・地図・効果音を付けていきます。

### まず無料で下見（おすすめ）

```
npm run assets -- src/scripts/history-honnoji.json --dry-run
```

「これからこういう絵をこういう指示で作りますよ」という一覧が出ます。
**この段階ではお金はかかりません。**

### 絵を作る（ここから課金されます）

```
npm run assets -- src/scripts/history-honnoji.json
```

信長と光秀の立ち絵 → 各カットの絵、の順に作られます。数分かかります。
できた絵は `public/photos/` フォルダに保存されるので、開いて見てみてください。

### 声を作る

```
npm run voice -- src/scripts/history-honnoji.json
```

ナレーション7カット分の音声ができます。

### 地図・効果音・BGM（無料・OpenAI不要）

```
npm run map
```

```
npm run sfx
```

```
npm run bgm
```

地図は国土地理院由来の無料データ、効果音とBGM（静かなピアノ曲）は
その場で計算して作るので、どれもAPIキー不要・無料・権利問題なしです。
市販の曲やフリーBGMを使いたい場合は `public/bgm/` にファイルを置いて、
台本の `bgm` にファイル名を書けば差し替わります。

## 5. 動画を書き出す

### まずプレビューで見る

```
npm run studio
```

ブラウザが開いて、動画を再生しながら確認できます。
見終わったらターミナルで `Ctrl+C`（Macも同じ）を押すと止まります。

### mp4 に書き出す

```
npx remotion render src/index.ts HistoryExplainer out/history.mp4
```

数分待つと `out` フォルダに `history.mp4` ができています。これが完成品です。

## 6. 自分の動画を作りたくなったら

台本は `src/scripts/` の中にある `.json` ファイルです。
メモ帳でも開けますが、**Claude Code に頼むのが一番楽**です。例えば:

> 「関ヶ原の戦いの解説動画の台本を書いて。絵と声のプロンプトも入れて」

と頼めば台本ができるので、あとは手順4→5を繰り返すだけです。

## うまくいかないとき

| 出たメッセージ | 意味と対処 |
|---|---|
| `command not found: node` | Node.js が入っていない。手順1へ |
| `command not found: git` | git が入っていない。手順2の注記へ |
| `OPENAI_API_KEY が設定されていません` | 手順3の「キーを教える」をやり直す（ターミナルを開き直すと忘れます） |
| `401 Unauthorized` | キーの文字列が間違っているか、削除済み。新しいキーを作る |
| `429` や `insufficient_quota` | OpenAI の残高切れ。チャージする |
| 絵の雰囲気が気に入らない | 台本の `imageStyle`（画風）を書き換えて、`--force` を付けて作り直す |

困ったら、出てきたエラーメッセージをそのまま Claude Code に貼り付けて
「これどういう意味？」と聞くのが一番早いです。

# BGM の置き場所

ここに音楽ファイル（mp3 / wav / m4a）を置いて、台本から参照する。

```json
{ "bgm": "bgm/calm.mp3", "bgmVolume": 0.25, "bgmDuckVolume": 0.07 }
```

- 曲が動画より短ければ自動でループする
- 冒頭と末尾は自動でフェードする
- **ナレーションが流れている間は自動で音量が下がる**（ダッキング）。
  声にBGMを同じ音量で被せると一気に素人っぽくなるため、既定で有効

音楽は画像や音声と違って生成していない。ライセンスの問題があるので、
使用条件を自分で確認したものを置くこと。

`public/voice/` の方は `npm run voice` が自動で作るので、手で置く必要はない。

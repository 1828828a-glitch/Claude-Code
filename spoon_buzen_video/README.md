# SPOON豊前 紹介動画（昼食版・夕食版、各60秒）

お弁当宅配「SPOON豊前」のサービス紹介動画です。企業・職場向けの昼食を紹介する昼食版と、ご自宅にも職場にも届ける夕食を紹介する夕食版の2本があります。映像は Canvas 2D、音は Web Audio API で、すべて JavaScript のコードから生成しています。画像や音声の素材ファイルは使っていません。

書き出し済みの動画（1920×1080、30fps、H.264／AAC）

- 昼食版 `dist/spoon-buzen-60s.mp4`
- 夕食版 `dist/spoon-buzen-dinner-60s.mp4`

## 見る

昼食版は `index.html`、夕食版は `dinner.html` を Chrome か Edge で開くと再生できます。画面上部の「昼食・夕食」で行き来できます。書体は Google Fonts（Zen Maru Gothic、Zen Kaku Gothic New、Fredoka）を読み込むので、ネットにつながった状態で開いてください。

プレイヤーの下にある構成リストから各場面に飛べます。`index.html?t=32.5` のように開くと、その秒数の画面から始まります。

## 文言を直す

画面に出る文字と連絡先は、昼食版が `js/copy.js`、夕食版が `js/dinner/copy.js` にまとめてあります。`{9:30}` のように波かっこで囲むと数字用の書体とアクセント色に、`[ちゃんと昼休み]` のように角かっこで囲むと強調（明るい背景では黄色のマーカー、夜の背景では黄色の文字）になります。行の長さは画面幅に合わせてあるので、大きく文字を増やしたときはプレイヤーで見た目を確かめてください。

場面ごとのタイミングは昼食版が `js/scenes.js`、夕食版が `js/dinner/scenes.js` の `TL` にあります。BGMと効果音の部品は `js/audio.js` で共通、譜面は昼食版が `js/audio.js` の中、夕食版が `js/dinner/score.js` です。効果音の時刻も `TL` を参照しているので、場面をずらすと音も一緒に動きます。

## 書き出す

手早く確認用の動画がほしいときは、プレイヤーの「WebMで書き出す」を押します。再生しながら記録するので60秒かかります。

入稿用の MP4 は Node.js で書き出します。

```sh
npm install
npx playwright install chromium   # 初回のみ
npm run render                    # 昼食版 → dist/spoon-buzen-60s.mp4
npm run render:dinner             # 夕食版 → dist/spoon-buzen-dinner-60s.mp4
```

ヘッドレスの Chromium で1コマずつ描画し、ffmpeg で H.264 に圧縮しています。`npm run stills`、`npm run stills:dinner` で確認用の静止画を出せます。ffmpeg は `ffmpeg-static` が入れば自動で使い、入らない環境では `FFMPEG_PATH` に ffmpeg の場所を指定してください。

## ナレーション

台本は昼食版が `NARRATION.md`（20カット）、夕食版が `NARRATION_DINNER.md`（16カット）です。どちらも画面のテロップが出る秒数に合わせて時間を割り振りました。プレイヤーの吹き出しボタン（キーボードなら N）を押すと、再生に合わせて今読む一文と次の一文が動画の下に出るので、録音のときはそれを見ながら読めます。編集ソフトに読み込める字幕ファイルは `dist/narration.srt` と `dist/narration-dinner.srt` です。

台本の中身は `js/narration.js` と `js/dinner/narration.js` にあり、直したあと `npm run narration`（夕食版は `npm run narration:dinner`）を実行すると、各カットの読む速さ（1秒あたりの拍数）を確かめたうえで表と SRT を作り直します。

## 内容の根拠と、あえて入れなかったもの

昼食版の商品仕様（40品目以上、7種類のおかず、管理栄養士監修、日替わり1000種類以上、当日9:30締切、9:30〜12:00頃の配達、電話番号）は SPOON公式LP（https://gluseller.com/lp/spoon）の記載をそのまま使っています。ストーリーとコピーは広報戦略資料（2026年9月26日版）のブランド仮説、4層の価値構造、漫画パンフ案から組み立てました。

昼食版では資料の方針に合わせて、次の3点を入れていません。

- 価格。現行の企業向け価格が未確認で、「安さ」を主訴求にしない方針のため
- 「1食から無料配達」をそのまま打ち出す表現。広域の小口注文を呼び込まないよう「少人数で試す」「届くか確認」に置き換えています
- 番地まで含めた住所。公開情報の間で表記が食い違っているため、「豊前市八屋」までにしています

12:00→12:35 の時間配分は漫画パンフ案と同じ物語上の設定で、調査データではありません。アンケート結果が出たら、`js/scenes.js` の `TL.s2.segs` を実態に合わせて調整できます。

夕食版の内容は、夕食チラシと夕食FAX注文票に書かれていることだけで組みました。メニューと価格、当日12時までの注文、14時〜17時（配達状況により最大18時）のお届け、ご自宅にも職場にも、宅配1個から無料、電話とFAXの番号がそれにあたります。価格と「宅配1個から無料」はチラシが前面に出しているので、昼食版とは扱いを変えて動画にも入れています。昼食の日替わり弁当についての「40品目以上」「管理栄養士監修」は、夕食メニューに当てはまるか確認できていないため使っていません。弁当のイラストはイメージで、実際のおかずとは異なります。

## 公開前に確認すること

- 「SPOON」の文字はロゴ画像ではなく書体で組んだ仮の表記です。FC本部のロゴ使用ルールを確認し、必要なら差し替えてください
- 昼食版エンドカードの電話番号とURLは、QRや豊前専用LPができたらそちらに替える想定です（`js/copy.js` の `s9.contact`）
- YesTry の紹介文（昼食版 0:51）の表現を YesTry側に確認してください
- 夕食版は配達エリアに触れていません。エリアに制限があるなら、エンドカードの注記（`js/dinner/copy.js` の `s10.note`）に足してください
- 冒頭と最後のチャイムはウェストミンスターの鐘（1793年、パブリックドメイン）の旋律を、BGMはこのコードで合成した音を使っています

# SPOON豊前 夕食の紹介動画 ナレーション台本

60秒の動画 `dist/spoon-buzen-dinner-60s.mp4` に合わせた台本です。ナレーションは16カットで、声が入るのは合計およそ42秒。昼食版より少し間を広くとり、夕方の落ち着いた時間に合わせています。

## 読み方の方針

前半の4文は、家と職場それぞれの心の声です。「今日の夕飯、何にしよう。」「今日は仕事が長引きそう。」は、ため息まじりのひとりごとくらいの温度で読みます。15秒の「夕食のことまで、手が回らない日がある。」で語り手の声に戻り、20秒でSPOONが出たところから一段明るくします。

50秒の「おいしいごはんで、毎日をもっとたのしく。」がいちばん温かい一文です。急がず、置くように読んでください。最後の「夕食のご注文は、当日12時まで。」はチャイムと重なるので、「12時まで」がはっきり届くことを優先します。

速さの目安は1秒あたり7拍前後で、表の「速さ」はどのカットも7.2以下です。

## 読みの注意

豊前は「ぶぜん」、FAXは「ファックス」と読みます。14時は「じゅうよじ」、17時は「じゅうしちじ」、750円は「ななひゃくごじゅうえん」、1個は「いっこ」です。

## 声を入れないところ

0:00〜0:05 は夕方のチャイムだけを聞かせ、チャイムに合わせて町の窓に明かりがともる時間にしています。0:18.6〜0:20.1 はSPOONが出る前の盛り上がり、0:28.8〜0:30.1 と 0:33.6〜0:35.1 は場面が切り替わるところ、0:47.9〜0:50.6 は画面が夜に変わるところです。59.5秒から先は音楽の余韻です。

## 収録と仕上げ

カットごとに分けて録り、前後に0.5秒ずつ余白を残しておくと並べやすくなります。`dinner.html` を開いて吹き出しのボタン（キーボードなら N）を押すと、再生に合わせて今読む一文と次の一文が動画の下に出ます。`dist/narration-dinner.srt` を編集ソフトに読み込めば、各カットを置く位置の目安になります。

声を重ねるときは、ナレーションの間だけBGMを8〜10dB下げてください。仕上がり全体を -14 LUFS 前後に合わせると、昼食版と並べても音量がそろいます。

## 秒数や言葉を変えるとき

台本の中身は `js/dinner/narration.js` にあります。直したあとに `npm run narration:dinner` を実行すると、各カットの読む速さを計算し直し、この表と `dist/narration-dinner.srt` を作り直します。

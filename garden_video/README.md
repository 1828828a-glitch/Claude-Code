# 8月の園芸 — ショート動画3本

縦型 1080×1920 / 30fps / 日本語ナレーション + 自前生成 BGM。
`intro_video/` で作った音声パイプラインを再利用し、**画面の文法は参考片の逐帧分解から取った**。

| 出力 | 尺 | 内容 |
|---|---|---|
| `out/garden/water.mp4` | 33.4秒 | 8月の水やり — 朝夕・たっぷり・置き場所 |
| `out/garden/pests.mp4` | 35.0秒 | 8月の病害虫 — ハダニ / アブラムシ / うどんこ病 |
| `out/garden/sowing.mp4` | 31.9秒 | 8月にまく秋冬野菜 — 下旬からの種まき |

## 参考片から採ったもの

`intro_video/shotcraft/reference/ref-mood-01`(「1分でわかる日本史」を100フレームに分解)の
三列表のうち、**構造と動きの文法だけ**を移植した。美術(金屏風・墨・筆文字)は
題材が違うので採っていない。配色は園芸から生やしている(深い葉陰・夏の陽射し・水・葉)。

シーン種別が、そのまま採用した手法に対応する:

| kind | 参考片の手法 | 実装 |
|---|---|---|
| `title` | 見出しが先に立ち、背景は後から浮上 | 見出し → 0.5s 遅れて背景の帯が下から上がる |
| `steps` | 主体を一つずつ、ラベルはさらに遅らせる二段構え | 各項目がセリフに同期して出る → **0.45s 遅れて**ラベルの pill が出る |
| `relation` | 関係を横線+中央ラベルで示す | 両者の箱 → 線が引かれる → 中央にラベル |
| `break` | 縦の亀裂で断ち切って大字を叩き込む | 亀裂が上から裂けて伸び、右に大字が過冲つきで着地 |
| `bright` | 明るい地へのハードカット(1本に1回) | 地と字が反転する。全編暗場の単調さを切る |
| `outro` | 字標が着地し、着地の瞬間に光が飛ぶ | 過冲つきで縮んで着地 → 白フラッシュ |
| (全編) | 字幕は常設レイヤー、隅に小注記 | 下部の字幕帯と右上の注記は全フレームに居る |

## 使い方

```bash
pip install pillow numpy imageio-ffmpeg pyopenjtalk
./intro_video/fetch_fonts.sh          # フォント(初回のみ)

python3 garden_video/build.py                  # 3本すべて
python3 garden_video/build.py --only water     # 1本だけ
```

| オプション | 既定値 | 説明 |
|---|---|---|
| `--only` | なし | slug(`water` / `pests` / `sowing`)で1本だけ作る |
| `--outdir` | `out/garden` | 出力先 |
| `--crf` | `20` | 画質 |

環境変数 `GARDEN_FONT_DIR` でフォント置き場、`FFMPEG_BIN` で ffmpeg のパスを指定できる。

## 内容を変えるとき

`specs.py` のデータだけで構成が決まる。`build.py` は触らなくてよい。

```python
dict(
    kind="steps",
    kicker="3つだけ",
    items=[("朝と夕方にやる", "accent", "昼はさける"), ...],   # (本体, 色キー, ラベル)
    lines=["覚えることは、3つだけ。", "朝と夕方にやる。", ...],  # ナレーション
    min_dur=9.0,                                             # 尺の下限
)
```

- `lines` の各要素が1つのキューになり、`steps` では **items[i] が lines[i+1] に同期**する。
  行を増減させたら items との対応を確認すること。
- 尺はナレーションの実長で決まる(`min_dur` は下限)。画面を音に合わせる方式なので、
  文言を変えると自動的に尺も変わる。
- 英語の固有名詞はカタカナで書く。Open JTalk は英字を一字ずつ読む。

## 内容についての注意

- 時期・手順は**地域と品種で変わる**。各本に注記を常設してある(種まき編は「※中間地の目安」)。
  断定を避けた言い回しにしているので、書き換えるときも同様に。
- 病害虫編は「症状が重いときは早めに対処を」を注記。具体的な薬剤名は出していない。
- ナレーション音声は HTS音声 "Mei"(CC BY 3.0、**帰属表示義務**)。公開時は出典表示が必要。
  `intro_video/make_intro_video.py` は末尾に出典を焼き込む実装があるので、必要なら同様に。
- BGM はコードによる完全な生成物で、既製曲は使っていない。

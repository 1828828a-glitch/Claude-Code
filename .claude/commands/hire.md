新しいAI社員を採用します。任せたい業務: $ARGUMENTS

あなたは採用担当として、以下の原則で進めてください。

**原則: 役職ではなく業務単位で、狭く定義する。**
「AI経理」ではなく「領収書ファイル名をルール通りに整理するAI」のように。

1. まず以下をヒアリングする（一度に全部聞かず、対話で埋める）:
   - その業務のインプットは何か（どのファイル・情報を見るか）
   - 合格のアウトプットはどんな形か（良い例があれば見せてもらう）
   - やってはいけないことは何か
   - どこで人間確認を挟むか
2. 業務範囲が広すぎる場合は、最初の一歩として狭い業務を提案し直す
3. ヒアリング結果を既存の指示書（`.claude/agents/ai-secretary.md` 等）と同じ構成でまとめる:
   担当業務 / 仕事の進め方 / 出力フォーマット / 禁止事項 / 完了報告
4. **指示書の案を見せて承認をもらってから** `.claude/agents/` に保存する
5. 保存後、CLAUDE.md の組織図にも1行追加する

# 画像生成（Codex CLI + GPT Image 2）

Claude Codeには画像生成モデルが載っていないが、Codex CLIには入っている。
そこで役割分担する：**どんな画像にするかはClaude（あなた）が考え、実際の生成はCodexに投げる。**
ユーザーはブラウザを開かず、ダウンロードもせず、今いる作業フォルダに画像を受け取れる。

## 手順

### 1. 事前チェック

まずCodex CLIが使えるか確認する：

```bash
codex --version
```

- コマンドが見つからない場合は、生成に進まずユーザーへ次を案内する：
  - インストール: `npm i -g @openai/codex`（Homebrewなら `brew install --cask codex`）
  - ログイン: `codex login` （ChatGPTアカウントでログイン。追加課金なし・APIキー不要）
- 実行時に認証エラーが出た場合も同様に `codex login` を案内する。

### 2. 画像プロンプトを設計する（ここがあなたの仕事）

ユーザーの依頼（日本語）から、**英語の詳細な画像プロンプト**を組み立てる。
ユーザーはコマンドも英語プロンプトも書かない前提なので、以下を自分で決める：

- **主題**: 何が描かれているか（具体的に）
- **スタイル**: flat illustration / watercolor / photorealistic / 3D render など。
  記事の挿絵なら、記事のトーンに合わせて選ぶ
- **構図・色**: 配置、背景、パレット、ライティング
- **用途に合った縦横比**: noteサムネ・X(Twitter)カバーなどは横長（16:9 や 1280x670）、
  アイコンは正方形、と用途から判断する
- **文字を入れない**: 画像内テキストは崩れやすい。ユーザーが明示的に求めた場合のみ入れる

依頼が曖昧でも聞き返しすぎない。記事本文や文脈があるなら、それを読んで自分で提案する
（このスキルの価値は「考えるところまで任せられる」ことにある）。

### 3. Codexに生成を依頼する

保存先はユーザーの作業フォルダ（またはユーザー指定の場所）。ファイル名は内容がわかる
英語のケバブケース（例: `article-cover-remote-work.png`）にする。

```bash
codex exec --full-auto --skip-git-repo-check -C <保存先ディレクトリ> \
  "Generate an image with GPT Image 2 using your image generation tool. Save it as <ファイル名>.png in the current directory. Do not create or modify any other files. Image prompt: <設計した英語プロンプト>"
```

- 画像生成には数分かかることがある。Bashのtimeoutは長め（600000ms）に設定する
- **複数枚の依頼**（「5枚まとめて作って」など）は、1枚ずつプロンプトを変えて
  `-01`, `-02`… と連番ファイル名で順に生成する。各枚のプロンプトはバリエーションを
  持たせつつテイストを揃える

### 4. 検証して報告する

生成後は必ず確認する：

1. `ls -la` でファイルが存在し、サイズが十分（数百KB以上が目安）であること
2. Readツールで画像を実際に見て、依頼内容と合っているか確認する
3. 明らかにズレていたら、プロンプトを修正して1回だけ再生成する

最後に、保存したファイルのパスと、どんなプロンプトで生成したかを日本語で簡潔に報告する。

## 失敗時の対応

- `codex: command not found` → 手順1のインストール案内を出して終了
- 認証エラー / login required → `codex login` を案内して終了
- Codexは完了したのに画像ファイルがない → codex execの出力を読み、保存先の指示を
  明確にして再実行（「Save it as ... in the current directory」を必ず含める）
- タイムアウト → 1回だけ再試行。それでも失敗ならユーザーに状況を報告する

## テイストの固定（カスタマイズ欄）

気に入ったスタイルが決まったら、下に条件を書き足しておくと毎回そのテイストで揃う。
ユーザーから「このテイストを覚えて」と言われたら、あなたがこの欄を編集すること。

```
（例）
- スタイル: 温かみのあるフラットイラスト、線は細め
- パレット: オフホワイト背景 + 青緑系アクセント
- 避けるもの: 写実的な人物の顔、画像内の文字
```

# ADTANK GP「デジブレ」展示会用 紹介動画（60秒）

レポート作成サービス（オリジナルAIエンジン「デジブレ」／ ADTURN for HR）を紹介する
展示会用のモーショングラフィックス動画です。

- 尺: 60秒（ループ再生を想定した構成）
- 解像度: 1920×1080 / 30fps / H.264 MP4
- スタイル: モーショングラフィックス・インフォグラフィック中心
- 訴求の軸: デジブレの技術的な新規性（トップパフォーマーの脳の転写・特許出願中）

## ファイル

- `index.html` — 動画本体（Canvasアニメーション）。ブラウザで開くと再生・シークして確認できます。
- `render-video.mjs` — フレーム書き出し＆MP4エンコードスクリプト
- `adtank-digibure-expo-60s.mp4` — 書き出し済みの完成動画（無音）
- `adtank-digibure-expo-60s-with-audio.mp4` — BGM＋ナレーション入りの完成動画
- `audio/` — BGM合成スクリプト・ナレーション音声・原稿（`audio/narration-script.md`）
- `remotion/` — 同じ動画のRemotion（React）実装。BGM・ナレーションも
  `<Audio>` コンポーネントとして組み込み済み。詳細は `remotion/README.md` を参照。

## 編集・書き出し方法

コピーや色、タイミングはすべて `index.html` 内の各 `sceneN()` 関数と定数
（`ACCENT` などのブランドカラー、シーン切替時刻）で調整できます。

書き出し:

```bash
npm install playwright        # Chromium 本体は別途必要
node render-video.mjs [出力パス] [ffmpegパス]
```

ffmpeg は libx264 対応のもの（例: `pip install imageio-ffmpeg` に同梱のバイナリ）を使用してください。

『おにぎり』篇 TikTok版 4パターン

絵も字幕も音楽も効果音も、すべてコードで生成しています。外部の素材サイトや画像生成サービスは使っていません。人の声は入れず、セリフとナレーションは字幕で見せる作りです。合成音声を当てると、泣かせどころで機械っぽさが勝ってしまうので見送りました。

書き出しはすべて縦1080×1920、30fps、H.264とAAC。出来上がりは out/ にあります。

  out/a.mp4  メイン版 45秒
  out/b.mp4  POV版 41秒
  out/c.mp4  Vlog版 44秒(PR表記入り)
  out/d.mp4  母視点の続編 42秒

映像の質感(第2版)

最初の版はフラットなイラストでした。第2版では、AI動画がきれいに見える理由のうち、コードで再現できる部分を描画エンジンに入れています。

  1コマを3回描いて重ねるモーションブラー。動く物がなめらかにぶれる
  明るい部分のにじみ(ブルーム)、色調の補正、動くフィルムの粒子、周辺減光
  背景だけをぼかす浅い被写界深度と、背景と人物の動く量を変えるパララックス
  光の筋の中を漂うほこり、炊きたてのご飯や鍋の湯気、居酒屋の煙と手前の玉ボケ
  人物の目の描き込み、髪のつや、顔と服の陰影、逆光の縁取り、呼吸と頭のわずかな揺れ

そのぶん書き出しは重くなり、4本を同時に書き出すと1本あたり10〜15分かかります。最初の版は git のタグ v1-flat に残してあります。

ここまでやっても、実写のような人の芝居には届きません。泣き顔やうなずきを実写の質で見せたいなら、人の出るカットだけを Seedance などの動画生成に任せて、字幕・チャット画面・音・編集をこの仕組みで重ねる分担がいちばん現実的です。


文字なし版(Veo で生成する前提)

クライアント要件(画面内の文字ゼロ、男性ナレーションを後乗せ)に合わせた A と C の設計一式は production/ にあります。進め方は production/進め方.txt にまとめました。プレビズは out/a_nt.mp4 と out/c_nt.mp4 で、尺はナレーションの長さから自動で決まります。


作り直すとき

  ./build.sh a     A を書き出す(b c d も同じ)

動画の中身は src/videos/a.js から d.js に、秒単位の台本としてそのまま書いてあります。字幕の文言やタイミングはこのファイルの caps を、音のきっかけは audio を書き換えれば反映されます。絵は src/ の Canvas 描画、音は audio.py の合成です。初回はフォントを自動で取得します(Zen Maru Gothic、Klee One、Yomogi、Zen Kaku Gothic New、いずれもOFL)。

必要なもの  Node.js と Playwright の Chromium、Python3 と numpy、ffmpeg

# 監督審査の記録(生成のたびに追記する)

作業者ではなく監督の目で見る。不合格のときは理由を一文で書き、「プロンプト修正でリテイク」か「設計を変更」かを決める。

1秒ごとのコマを並べて確認するコマンド:

```bash
ffmpeg -i shots/SH-BITE.mp4 -vf "fps=1,scale=240:-1,tile=8x1" review_SH-BITE.jpg
```

## チェック項目

- 意図(そのカットの役割)が一目で伝わるか
- 演技の強さは設計どおりか(shotlist の「演技」列の数値)
- 人物の顔・髪・服が参照画像と一致しているか(前後のカットと並べて確認)
- 小道具は正しく認識できるか(赤ウインナーが鮭に見えないか)
- 画面内に文字・ロゴ・透かしが無いか(1秒ごとのコマで確認)
- 手指・食べ物・液体の破綻が無いか
- 前後カットとアングル・サイズが被っていないか
- 口元が見える状態でしゃべっていないか(後乗せの声と合わないため)

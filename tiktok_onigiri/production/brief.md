# brief おにぎり篇 TikTok(A 反抗フック版 / C Vlog版)

## 前提(ヒアリング項目は調査メモの記載から確定)

- 縦 9:16、1080×1920、40〜45秒(プレビズ時点で A 43.1秒、C 41.0秒)
- 構成は A がフック→居酒屋→ひとり暮らし→回想→送信、C が Vlog の時系列(朝6時半→弁当作り→回想→送信→電車に間に合う)
- 画面内の文字・字幕・PR表記・ロゴ・透かしはゼロ。PR の表示は TikTok のブランドコンテンツ設定と投稿文の #PR で行う
- 音声は男性ナレーションを TTS で後乗せ(Edge TTS の ja-JP-KeitaNeural 想定)、BGM と効果音
- 生成は Google Flow の Veo 3.1 Fast(Ingredients で参照画像を入れる)。1カット8秒、20クレジット
- 未確認なのは残りのクレジット数だけ。見積もりは generation_list.md

## 狙い

見終わったあとに、自分も親に何か送ろうかな、と一瞬スマホを見てしまう。泣かせるのではなく、喉の奥が少し詰まるくらいで止める。

見る人は、親元を離れて数年の20代。残したい一言はナレーションの「オープンアップしよ。」で、言葉より先に、送信ボタンを押す親指で伝える。

## 全体の設計

A は冒頭の背中越しのひと言でスクロールを止め、居酒屋の断面で音を消し、回想はセピアで速く、最後の送信だけはゆっくり見せる。山は二つで、居酒屋の無音と、送信の直前の迷い。

C はローファイのビートに乗った軽い朝の Vlog として始まり、「……ソーセージ。」の直前でビートを止める。そこから回想に入り、作って送って電車に間に合う流れでビートが戻る。A で目の前で閉まった電車のドアを、C では間に合わせる。

色と光は、現在の朝が冷たい青から暖色へ、居酒屋は電球色の暖かさ、回想は仕上げで掛けるセピア寄りの色。生成の段階では回想も普通の色で作り、色は ffmpeg でそろえる(カットごとに色がぶれないようにするため)。

カメラは基本が手持ちのわずかな揺れ。寄りのカットは背景を大きくぼかす。真上からの手元カットを要所に挟み、正面の顔のカットと交互にする。

## ルール

1. 人物が画面に向かってしゃべるカットは作らない。生成した口の動きと後乗せの TTS は合わないので、声は画面外か、聞いている側の表情の上に乗せる
2. 似たカット(同じサイズ、同じ向き)を続けない。顔の寄りの次は手元か引き
3. 平板な絵を許さない。どのカットにも光の向きと、手前・奥の距離を作る
4. 小道具の赤ウインナーは、断面で赤い輪とピンクの中身が見えること。鮭に見えたら不合格
5. 画面に文字が出たら不合格。提灯・張り紙・パッケージ・黒板・スマホの画面は、無地にするか画角から外す
6. 回想と現在は色で区別する。回想のカットには仕上げで回想グレードを掛ける(shotlist の「仕上げ処理」列)

# inbox/ — 依頼と素材の置き場

AI社員に処理してほしい素材（議事録、商談メモ、記事ネタなど）をここに置いて、
チャットで「inboxの◯◯を処理して」と頼んでください。

## ファイル名の付け方

`YYYY-MM-DD_(種類)_(内容).md`

例:
- `2026-07-16_gijiroku_teirei.md` → ai-secretary が処理
- `2026-07-16_shodan_yamada-sama.md` → ai-sales が処理
- `2026-07-16_kiji-neta_ai-katsuyo.md` → ai-editor が処理

処理が終わった素材は人間が削除するかアーカイブしてください（AIは削除しません）。

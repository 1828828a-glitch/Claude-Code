# company/ — AI会社の共有ドライブ

AI社員が参照・出力するための場所です。

| フォルダ | 用途 | 書き込むのは |
|---|---|---|
| `rules/` | 全社ルール（文体・禁止表現・承認フロー） | 人間のみ |
| `knowledge/` | AI社員に読ませる情報（商品・顧客・過去の成功例） | 人間のみ |
| `templates/` | アウトプットの型 | 人間のみ（AIは提案まで） |
| `inbox/` | 人間からの依頼・素材（議事録、商談メモなど）を置く | 人間 |
| `output/` | AI社員の成果物。**すべて人間レビュー待ち扱い** | AI社員 |

## 運用のコツ（小さく始める）

1. まず `knowledge/` に自分の商品情報・過去の成功例を1つ置く
2. `inbox/` に素材を1つ置いて、対応するAI社員に頼む
3. `output/` の成果物をレビューして、直した点を `rules/` や `templates/` に反映する
4. これを繰り返すと、AI社員が育つ（＝指示書とルールが育つ）

# output/ — AI社員の成果物置き場

ここにあるものは**すべて人間レビュー待ち**です。そのまま外部に出さないでください。

## レビューの回し方（これがAI社員を育てる）

1. 成果物を読む
2. 直した点・違和感を、そのAI社員に伝えて修正させる
3. **繰り返し出る指摘は、ルール化する**
   - 文体の指摘 → `company/rules/style-guide.md` に追加
   - 手順の指摘 → `.claude/agents/` の指示書に追加
   - 良い完成形 → `company/knowledge/wins/` に保存

レビューして終わりにせず、指摘をルールに昇格させることで、同じ指摘が二度と要らなくなります。

# knowledge/ — AI社員に読ませる情報

ここに置いた情報だけをAI社員は「事実」として使えます。
**ここにない情報は、AIは使ってはいけない（でっち上げ防止）。**

## 最初に置くとよいもの

- `product.md` — 商品・サービスの説明（価格、対象顧客、強み）
- `customers.md` — 顧客の傾向、よくある課題、NG対応
- `wins/` — 過去の成功例（刺さった投稿、通った提案、良かった記事）

## ルール

- 更新は人間のみ。AI社員は読み取り専用
- 古くなった情報は消すか「(旧)」を付ける — AIは新旧を区別できない
- **機密情報・個人情報はリポジトリに置かない**（顧客の実名等はイニシャル化を検討）

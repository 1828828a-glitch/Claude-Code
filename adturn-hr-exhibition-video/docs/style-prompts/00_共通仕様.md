## 4. BGM設計ルール

- 165秒フル尺。**問い区間(23.8-56.3s / 90.7-109.2s)は静める**、**リフト区間(56-72s / 126.5-140s / 148-165s)は一段上げる**
- 加えてRemotion側でボリュームダッキング(問い区間 -0.1〜0.12)
- 生成は `remotion/scripts/gen_bgm_full4.py` の方式(numpy合成→wav→aac)を踏襲

## 5. 制作パイプライン(Remotionの場合)

1. `remotion/src/<style>/` にコンポーネント作成。タイムラインは `V3D_SCENES` を使用、`Video.tsx` のNARRATION表をコピー
2. **Sequence内はローカルフレーム**(`useCurrentFrame()`は0始まり)。絶対フレームでdelayを書かない(過去の実バグ)
3. 3D(頭部GLB)を使う場合: ジオメトリのロードは必ずThreeCanvasの外(`useHeadGeometry`)。クリッピング平面はフタのワールド変換に毎フレーム追従させる
4. `Root.tsx` にComposition登録 → `npx tsc --noEmit` → 各シーンの静止画を `npx remotion still` で出して目視検証(560px縮小JPEGで確認)
5. `npx remotion render src/index.ts <CompId> out/xxx.mp4`(3Dなしなら約10分、S1のみ3Dで20-40分)
6. 納品は30MiB以下。超えたら `-crf 23` で再エンコード。BGMなし版は `out/narration_only.m4a` を `-c:v copy` で差し替え(再レンダリング不要)

# スタイルA: ニューロン・マイクロスコピー

> カメラは2分39秒、一度も脳の外に出ない。シナプスの海の中で台本が語られる。

## コンセプト
生きた脳組織を蛍光顕微鏡で覗いている映像。ニューロン(神経細胞)の網が奥行きボケの中で漂い、ナレーションに同期して電気信号が軸索を走る。**課題=断線して暗い / 解決=結線して発火**という神経のメタファーで全編を貫く。

## ビジュアル文法
- **背景**: 深海ネイビー #041018。完全な黒にしない(組織液の濁り)
- **主役**: 多層のニューロン網。細胞体(ソーマ)=発光する不定形の粒、樹状突起=細いベジェ曲線が枝分かれ。最低3層(奥=強ボケ低不透明 / 中=主役 / 手前=大きく強ボケで横切る)
- **発光色**: シアン #5FE8FF が基本。強調・打開策の瞬間だけ金 #FFD98C の軸索が走る
- **信号**: 輝点が突起の上を走る(2〜6個/シーン)。ナレーションの句点に合わせて発火
- **浮遊物**: 顕微鏡のボケ玉(ぼんやり丸い光)が常時ゆっくり漂う
- **HUD**: 四隅に極小モノスペース計測テキスト(SPECIMEN 001 / SYNAPSE DENSITY 8.4×10³ / DEPTH -120µm 等)。明滅・書き換わりあり
- **タイポ**: 見出しはゴシック太字白+キーワードのみシアン。HUDは細字レタースペース広め
- **カメラ**: 常にゆっくり漂う(ドリフト+微小回転)。ハードカット禁止、シーン転換は「別の組織へ泳いで移動」するクロスディゾルブ

## シーン別演出(要点)
| シーン | 演出 |
|---|---|
| tech | 暗闇→1個のニューロンが発火→網全体へ連鎖発火。宣言テキスト。「転写」で金の信号が走る |
| engine | 40個の細胞体が順に点灯(カウンター同期)。後半は2つの網を対比(疎な網=既存AI / 密に発火する網=デジブレ) |
| intro/q1-q3 | 問いのたびに信号が途切れ、暗い断線部が見える。巨大ゴースト数字は薄い発光で奥に |
| answer | 断線部が一気に結線→全域発火。ADTURN for HRロックアップ。4レポート=培養プレート風カード |
| nogen | 全信号停止の静寂→「一般論は、一行もない。」だけが光る |
| mintro〜mq3 | 別の脳領域へ移動(色温度をわずかに変える)。同じ断線メタファー |
| mscope | 4つの領域が順にスキャン発光(速)→全景引き(遅)→ロードマップ=信号が一本の太い経路に収束 |
| mreveal/finale | 2つの発火網がデジブレ(ひときわ明るい細胞核)から伸びている全景。最後は核が画面いっぱいに発光→デジブレロゴ |

## BGM
ダークアンビエント+心拍パルス(既存 `bgm_vaience_full.m4a` 系)。発火の瞬間に低いブーム。

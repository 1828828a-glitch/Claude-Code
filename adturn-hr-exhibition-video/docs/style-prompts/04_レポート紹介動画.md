# レポート紹介動画(クライアント個社向け・約90秒)

> 「デジブレの紹介」ではなく、**出力したレポートそのものの紹介**を、そのレポート元(対象)企業に見せるための動画。
> 見せ方は2パターンある。**まずどちらで作るかを決める**こと。

## 2つのパターン

| | パターンA: 実物エビデンス型 | パターンB: 業種メタファー型 |
|---|---|---|
| 参考実装 | まつや向け(本・実紙面が主役) | 産業ガス企業向け(配管・バルブの概念CGが主役) |
| 映像 | レポート実物+**実紙面のスクショ** | **その企業の事業世界のメタファーCG**のみ。紙面は出さない |
| 具体性の担い手 | 紙面そのもの(証拠) | **文字とナレーション**(映像は概念に徹する) |
| 強み | 証拠性・「中身が本当にある」信頼 | 情緒・記憶・「うちを分かってる」という当事者感 |
| 弱み | 紙面の文字が小さく読みにくい/中身が映像に露出 | 制作コスト高(企業ごとにメタファー設計+素材生成) |
| 向く相手 | 論理で買う会社・実務担当者への説明 | 経営者への提案・世界観で口説く商談 |
| 機密 | レポート内容が映像に写る | **一切写らない**(社外に出ても安全) |

### パターンBの設計原則(産業ガス実装の分析から)
1. **メタファー辞書を最初に作る** — 対象企業の業種から素材言語を決める(ガス会社→配管・圧力・流量・バルブ)。全シーンをその一つの世界で貫く。継ぎはぎ禁止
2. **概念とメタファーは1対1** — 「4層のボトルネック」=文字通りボトルネック形状の配管、「採用の言葉と実態」=太いパイプと細いパイプ、「意思決定」=分岐点のハンドル。飾りではなく**論旨の図解**として機能させる
3. **具体は映像に語らせない** — 数字・固有名詞・施策名はテロップとナレーションのみ。映像は抽象に徹する(=安っぽくならない・間違えない)
4. **色を記号として固定** — 例: オレンジ=実態・実力(熱)、青白=言葉・条件(冷)。全編で一貫させる
5. **黒の余白を恐れない** — 画面の半分以上が闇でよい。テキストの置き場所と高級感の源泉
6. 構成は下の9ビートと同じ(ギャップ→錯誤→翻訳→読み替え→勝ち筋→クロージング)。**変わるのは画だけ**

### パターンB用の素材生成プロンプト雛形(Runway/Veo)
> cinematic industrial CG of {業種モチーフ}, dark black background, dramatic rim lighting, one element glowing {オレンジ or 青白}, photorealistic, no text, no people, slow camera
> 例(ガス): a cross-section of an industrial bottleneck pipe with turbulent glowing vapor squeezed through four narrowing chambers ／ four massive pipelines stretching to the horizon with beams of light ／ an industrial steering valve at a junction of two paths

## 参考実装A: 株式会社まつや向け 採用戦略レポート〈武器編〉(1:30)

## 今までの展示会用動画との差分(重要)

| | 展示会用(00〜03) | レポート紹介用(この文書) |
|---|---|---|
| 目的 | ADTURN/デジブレという**製品**を売る | 出力された**レポートの価値**を見せて商談を前に進める |
| 観客 | 展示会の不特定多数 | **特定の1社**(レポートの対象企業=見込み客) |
| 主役 | 技術(脳・転写・エンジン) | **レポート実物**(本、紙面、中身の知見) |
| 台本 | 全スタイル共通の固定台本 | **企業ごとに完全カスタム**。汎用文はほぼゼロ |
| 素材 | 汎用プレート(ニューロン等) | **実レポートのスクリーンショット**+レポート実物のAI生成ショット |
| 尺 | 2分39秒(4775f) | **約90秒**(2700f)。商談前に見せ切れる長さ |
| 構造 | 宣言→問い→製品→CTA | ギャップ提示→誤解の特定→読み替え→space→実装→クロージング |
| 決め文句 | 「デモ実施中/ブースで体験」 | 「トップパフォーマーの知性を、組織の武器へ。」 |
| デジブレ言及 | 主役 | **ほぼ出さない**(レポートの説得力で語る) |

本質: 展示会用は「うちの脳はすごい」、レポート紹介用は「**あなたの会社はこう見えていて、こう直せる — その証拠がこのレポート**」。

## ビジュアル文法

- **背景**: 深い紺黒(#050a12系)+うっすら星屑/グリッド。展示会ニューロン版v2の「静かなトーン」と同系
- **実物ショット**: AI生成(Veo等)の「本が机にある/開く/ガラスケースの模型」。表紙は無地で生成し、社名はRemotionで合成
- **紙面ショット**: 実レポートのスクリーンショットを、微小な3Dチルト+ゆっくりしたズーム(Ken Burns)で。読める解像度を保つこと
- **字幕**: 下部1/3に暗色ボックス+白文字。**キーワードのみシアン(肯定/解決)または赤(問題/錯誤)+下線**。1画面1メッセージ
- **色**: 白/シアン#5FE8FF(価値・解決)/赤#E5484D(誤解・問題)の3色運用
- **BGM**: 静かなアンビエント(展示会用bgm_vaience系の音量控えめ)。ナレーションは任意(字幕だけでも成立する設計)

## 制作に必要なインプット(企業ごと)

1. 社名・レポート名(例: 株式会社まつや 採用戦略レポート〈武器編〉)
2. 実レポートの紙面スクリーンショット5〜8枚(PNG、錯誤の特定/読み替え/カウンタートーク/Phase表など「絵になるページ」)
3. コピー12〜15本(上の構成表に流し込む。レポートの結論から抽出)
4. キラー読み替え1つ(Before→After。例:「工場作業員」→「ソウルフードの守り人」)
5. (任意)ナレーション原稿 → edge-tts Keitaパイプラインで生成可

## Remotionテンプレート

`remotion/src/report/ReportVideo.tsx`(Composition: `AdturnReport`、2700f)が実装済み。

紙面PNGは `public/report/` に置く。プレート(rep_book/rep_open/rep_model)は汎用なので全企業で使い回し可。

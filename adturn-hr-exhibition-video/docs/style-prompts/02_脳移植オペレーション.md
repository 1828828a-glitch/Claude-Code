# スタイルB: 脳移植オペレーション・ライブ

> 動画全体が、ひとつの「脳移植手術」の実況モニタ。視聴者はオペ室のスクリーンを見ている。

## コンセプト
「トップパフォーマーの脳を転写する」を文字通り**手術ナビゲーションUI**として描く。MRI断面、バイタル波形、進行ゲージ。15シーンが手術の工程表に対応し、動画の進行=オペの進行。ADTURNリビール=移植成功。

## ビジュアル文法
- **背景**: 臨床モニタの黒 #0A0E12 + 極薄グリッド
- **配色**: メディカルティール #4AE3B5(正常)/ アラートアンバー #FFB648(問い・警告)/ 白(データ)。血赤は使わない(生々しさ回避、品位優先)
- **中央**: 頭部の断面スキャン(輪郭線+等高線+スキャンライン走査)。脳領域だけ塗りで発光
- **左パネル**: ECG心拍波形(常時アニメーション)、HR/SpO2数値
- **右パネル**: 工程チェックリスト。SCAN → EXTRACT → TRANSCRIBE → VERIFY → DEPLOY が順に完了していく
- **下部**: 進行バー「TRANSPLANT ██████░░░░ 62%」+タイムスタンプ(実時間と同期)
- **タイポ**: 数値はtabular-nums。見出しはゴシック太字白+ティール強調
- **効果**: スキャンライン、微小なUIちらつき、ワンポイントのグリッチ(多用禁止)

| シーン | オペ工程 | 演出 |
|---|---|---|
| tech | PHASE 0: INCISION | 頭部スキャンの頭頂部が開き(パカーン=開頭)、脳が摘出リフトされる。「転写する。」でTRANSCRIBE開始 |
| engine | DONOR ARCHIVE | ドナー台帳UI: 40件の移植記録が並ぶ(ID・領域・STATUS: COPIED)。後半は出力比較モニタ |

| answer | PHASE 2-3: TRANSCRIBE/GRAFT | ドナー脳の回路が患者側へ流し込まれる。4レポート=処方箋様式のカード。バイタル安定 |

## BGM
心拍モニタ音(75bpm、ピッ…ピッ…)+緊張の低音パッド。リビールで心拍が安定に転じ、パッドが解決する。フィナーレはモニタ音+温かいコード。

# 大炎上シミュレーター「ボヤッター」🔥

どんな投稿をしても必ず燃える、架空SNS炎上シミュレーターです。

`index.html` をブラウザで開くだけで遊べます(依存なし・単一ファイル)。

## 遊び方

1. 投稿を書く(思いつかなければ「燃えそうな例文ガチャ」)
2. 火力を選ぶ(弱火 🕯️ 〜 業火 ☄️)
3. 投稿する。あとは燃えるのを見守る

## 特徴

- 炎上レベル 0〜8:くすぶり → ボヤ → 炎上 → 大炎上 → 特大炎上 → 国家レベル → 世界規模 → 観測史上最大
- テレビ速報テロップ・まとめサイト・スポンサー声明・海外報道・国連・神が乱入
- 燃料投下ボタン(反論/言い訳/謝罪/別垢で自演擁護/法的措置)— **何をしても悪化します**
- 投稿内容に反応:食べ物や「〜派です」系の意見には専用の燃え方をします
- 効果音つき(通知音+速報チャイム。🔊ボタンでミュート可)
- 最後に「炎上結果通知書」を発行:炎上偏差値・獲得称号・推定損害額・自動生成謝罪文
- 結果は **画像(PNG)で保存** してSNSに貼れます
- エンディング分岐:即逃げで「賢者」、燃料なしで完走すると「無給油の伝説」など
- タブを切り替えても炎上は進行します。戻ってきた頃には手遅れです

※フィクションです。実在の人物・団体・スポンサー様・国連・神とは一切関係ありません。

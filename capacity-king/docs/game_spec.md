# Claude Fable 5 実装指示書

## プロジェクト名

**CAPACITY KING — ぜんぶ、もっとよくする。**

横長PCブラウザ向け、5〜8分で完結する2Dアクション＋判断ゲームのデモを制作してください。

このゲームは、大柄で許容力のある営業責任者を主人公にした誕生日企画です。笑える身内ネタを入口にしながら、最終的には「周囲を平和にし、みんなをハッピーにするために、要望を受け止め、よりよい案へ変換して前に進める人」への感謝が伝わる内容にします。

単なる大食いゲーム、肥満いじり、糖尿病いじりにはしないでください。体格や体調はキャラクターの特徴として扱いますが、笑いの中心は「無茶ぶりの量」と「状況を改善する提案力」に置いてください。

---

## 最重要ゲームデザイン

このゲームの勝利条件は、敵を倒すことでも、すべてを引き受けることでもありません。

プレイヤーは、飛んでくる食べ物、仕事、相談、トラブルを次の4段階で処理します。

1. **受け止める**
2. **状況を理解する**
3. **よりよい案に組み替える**
4. **提案し、周囲を前に進める**

### 必須の進行ルール

- すべてを無条件に受け入れると、主人公のキャパシティと健康が低下する。
- HOLDで止めるだけでは、時間が止まり、周囲の幸福度が徐々に低下する。
- 要望を捨てたり拒絶するだけでも、信頼度が低下する。
- **BETTER PLAN（よりよい提案）を成立させたときだけ道が開き、物語が進む。**
- 正しい提案は「主人公だけが楽になる案」ではなく、本人、仲間、家庭、顧客、子どもの全体幸福を高める案とする。

ゲームの中心メッセージは以下です。

> 平和は、何もしないことで生まれるのではない。  
> 誰かの困りごとを受け止め、みんなが前に進める案に変えることで生まれる。

## 技術要件

- Phaser 3
- TypeScript
- Vite
- 画面比率：16:9
- 基準解像度：1280 × 720
- PCブラウザ向け
- Chrome / Edge / Safariの現行版で動作
- バックエンド、ログイン、外部API、課金機能は不要
- `npm install` → `npm run dev` で起動
- `npm run build` がエラーなく完了
- キーボード操作を中心とするが、画面上のボタンをクリックしても操作可能にする
- 既存ゲームや既存キャラクターをコピーしない。カービィを想起させる丸い吸い込みキャラクターにはしない
- 高品質な16bitアーケードゲーム風。90年代プロレスゲームとコミカルな経営シミュレーションを融合する

### コード設計

- `src/scenes/`：各シーン
- `src/entities/`：主人公、ゴリラ、AIロボット、NPC
- `src/systems/`：ゲージ、提案、教育問題、スコア
- `src/content/`：問題・会話・選択肢をJSONまたはTypeScriptオブジェクトで管理
- `src/config/`：ゲーム定数
- `public/assets/`：画像と音声

教育問題や会話をコードに直書きせず、後から差し替えられるデータ駆動型にしてください。

## 主人公

### キャパシティ・キング

- 日本人男性をモチーフにした、身長180cm以上、体重100kg前後の大柄な人物
- プロレスラーのような堂々とした体格
- スーツ、白いシャツ、腕まくり、チャンピオンベルト風のベルト
- 強面ではなく、受容力と安心感のある表情
- 食べ物や相談を受け止めると一時的に大きくなる
- BETTER PLANを成功させると、蓄えたエネルギーが周囲へ金色の波として広がる
- 攻撃技は持たない
- 必殺技は「もっといい案があります！」

主人公は世界征服ではなく、**自分の周囲を平和にすること**をモチベーションにしている人物です。

---

## 相棒キャラクター

### ゴリラ部下

- キャラクター設定上の数値：身長188cm、体重140kg
- 巨大で力強いが、愛嬌があり、ネクタイを着用
- 営業力と行動力は高い
- 体調を崩しやすく、突然座り込んだり、汗をかいたりする
- 糖代謝リスクを抱えている設定
- バナナが好きだが、バナナを無制限に与えると回復せず、コンディションゲージが悪化する
- 体調悪化を笑いものにせず、「状態を見ずに同じ対応を続けるマネジメントの失敗」として表現する

### ゴリラの管理パラメーター

- `ENERGY`：行動力
- `CONDITION`：体調
- `TRUST`：主人公への信頼
- `HUNGER`：空腹
- `STRESS`：ストレス

### 対応アクション

- バナナを1本渡す
- 水を渡す
- バランスのよい食事を提案する
- 少し歩く
- 休ませる
- 話を聞く
- 役割を任せる
- 健康チェックを勧める

「バナナを連打すれば正解」にはしないでください。食事量、運動、休息、本人の状態を見て選ぶゲームにします。医療診断や具体的な治療指示は行わず、ゲーム内には「健康表現は演出であり、体調に不安がある場合は医療機関へ」という短い注記を入れてください。

## 主要ゲージ

画面上部に以下を常時表示します。

### WORLD PEACE / 周囲の平和度

ゲーム全体の最重要ゲージ。

- 園児、保育士、家庭、部下、顧客の幸福を統合した数値
- 0になるとゲームオーバー
- 100になると画面が明るくなり、背景の人物が笑顔になる
- プレイヤーが停止して何も決めない間も少しずつ減少する

### CAPACITY / 主人公の余力

- 無条件に引き受け続けると減少
- 役割分担、AI活用、BETTER PLANで回復

### TRUST / 信頼

- 要望を理解せず捨てると低下
- 一度受け止めて意図を理解し、代案を出すと上昇

### TEAM CONDITION / チーム状態

- ゴリラ、AIロボット、園職員の状態を統合
- 主人公だけが動き続けると低下

## 操作方法

- 矢印キー / WASD：移動
- SPACE：受け止める
- H：HOLD。一度止めて考える
- 1 / 2 / 3：提案カードを選択
- ENTER：BETTER PLANを実行
- G：ゴリラへの対応メニュー
- A：AIロボットへの業務委任メニュー
- ESC：ポーズ

画面下部に常時、簡潔な操作ガイドを表示してください。

## ゲーム構成

### TITLE

- 主人公、ゴリラ、AIロボットが横並び
- 背景は飲食店街、会社、保育園、家庭が一つの街としてつながっている
- タイトル：`CAPACITY KING`
- サブタイトル：`ぜんぶ、もっとよくする。`
- 「GAME START」「HOW TO PLAY」

### TUTORIAL：受け止めるだけでは守れない

ボスがラーメン、焼き肉、ポテトチップスを次々に主人公へ渡す。

- SPACEで食べると一時的にPOWERが増える
- 連続して食べるとCAPACITYが減る
- HOLDすると世界が停止する
- 「小盛りにする」「みんなで分ける」「次回の楽しみにする」からBETTER PLANを選ぶ
- 正しい提案で料理が金色の幸福エネルギーへ変わり、街へ広がる

### STAGE 1：GORILLA MANAGEMENT

ゴリラが大量の営業案件を抱え、空腹と疲労で暴走寸前になっている。

イベント例：

1. 空腹だからとバナナを3本要求する
2. 直前にも甘い物を食べていることがステータス画面で分かる
3. プレイヤーは状態を確認する
4. 「バナナ3本」「水＋休憩」「本人と相談して食事と仕事量を調整」から選ぶ
5. 最も全体状態を改善する案でのみ進行

後半では、ゴリラに仕事を任せないと主人公が倒れ、任せすぎてもゴリラが倒れる。仕事量を分配し、休憩を含む営業計画を提案する。

### STAGE 2：NURSERY DX PANIC

保育園に以下の課題が飛び交う。

- 手書き連絡帳
- 電話連絡
- 写真整理
- シフト作成
- 多言語のお知らせ
- 保護者対応
- 子どもとの対話

プレイヤーはAIロボットを使うが、全部をAIに任せるとHUMANITYが低下する。

正しい役割分担：

- 集計、下書き、翻訳、整理：AI
- 子どものケア、保護者との重要な対話、最終判断：人
- AI出力の確認：職員

BETTER PLAN成立時、書類の山が消え、保育士が子どものそばへ戻り、WORLD PEACEが上昇する。

### STAGE 3：LEARNING PEACE LAB

英語、算数、論理、感情理解を使って街の問題を解く教育ステージ。

#### 英語問題

- 食べ物の英単語
- 園生活で使う簡単な英語
- 感謝、共有、感情確認のフレーズ
- 単なる和英変換ではなく、場面に合う言葉を選択

例：食べ物を分けたい場面 → `Let's share.`

#### 算数問題

- 12枚の焼き肉を4人で均等に分ける
- 10本のバナナを、今食べる分と後で食べる分に分ける
- 園児20人を5人ずつのグループにする
- 30分の作業を40％短縮した場合の時間を求める
- 100園を5人で担当する場合の基本配分を考える

問題に正解すると、ゲーム世界の食事、人員、時間が実際に再配置されるようにしてください。

#### 感情・論理問題

- 困っている子どもの表情を読み取る
- ゴリラが疲れている理由をステータスから推測する
- 一つの正解に限定せず、複数の案が異なるゲージへ影響する問題も用意する

### FINAL STAGE：MAKE THE WORLD BETTER

ボスが最終指令を出す。

> 「保育業界を、全部変えてくれ！」

#### 失敗分岐

- そのまま全部引き受ける：主人公が巨大化して動けなくなり、周囲の幸福度が下がる
- 断って終わる：時間が止まり、園児、職員、部下、家庭の表情が暗くなる
- 考え続けるだけ：WORLD PEACEが徐々に減る

#### 唯一の進行分岐

プレイヤーが以下を組み合わせて提案する。

- まず3園で実証する
- AIは事務作業を支援する
- ゴリラは現場の声を集める
- 園職員は子どもと保護者に向き合う
- 主人公は課題を整理し、全体提案を作る
- 成果を事例化し、他の園へ横展開する
- 家庭と健康の時間も計画に含める

成功時の主人公の台詞：

> 「全部を一人で変えることはできません。  
> でも、みんなの力を組み合わせれば、  
> 今よりもっといい未来にできます。  
> もっといい案があります！」

提案が成立すると、止まっていた世界が動き出す。暗かった街に色が戻り、保育園、会社、家庭が一つの平和な街としてつながる。

## 教育サービスへの拡張性

デモ実装の時点で、教育コンテンツを追加できる構造にしてください。

### コンテンツモード

- `birthday`：誕生日・人物ネタ
- `preschool`：数、形、色、感情、簡単な英語
- `elementary`：四則演算、英語、論理問題
- `nursery`：園生活、協力、感情表現、安全
- `nursery-dx`：保育業務の改善提案
- `sales-training`：顧客課題から代案を作る

### 問題データの想定形式

```ts
type LearningChallenge = {
  id: string;
  mode: 'birthday' | 'preschool' | 'elementary' | 'nursery' | 'nursery-dx' | 'sales-training';
  subject: 'english' | 'math' | 'logic' | 'emotion' | 'dx';
  gradeLevel: string;
  situation: string;
  prompt: string;
  choices: {
    label: string;
    effects: {
      peace: number;
      capacity: number;
      trust: number;
      teamCondition: number;
    };
    feedback: string;
  }[];
  recommendedChoiceIndex: number;
};
```

将来的に先生や研修担当者が問題を登録できる画面へ拡張できるよう、UIとゲームロジックを分離してください。ただし今回のデモでは問題編集画面を作らなくて構いません。

## サウンド

- 明るい16bitアーケード調BGM
- 危機時も恐怖音ではなく、少し慌ただしいコミカルな音
- BETTER PLAN成功時は鐘、歓声、金色の波の効果音
- ゴリラの体調悪化時は警告音を鳴らすが、嘲笑する音声は使わない
- 音声素材がなければWeb Audio APIで簡単な効果音を生成してよい
- ミュートボタンを必ず設置

## デモの完成条件

1. タイトルからエンディングまで通してプレイできる
2. プレイ時間5〜8分
3. 受け入れ続ける、止め続ける、よりよい提案を出す、の違いがゲージと周囲の表情に反映される
4. BETTER PLANを出さない限りステージが進まない
5. ゴリラは188cm・140kgの設定がステータス画面に表示される
6. バナナ連打が正解にならない
7. 英語問題3問、算数問題3問、論理・感情問題2問以上を実装する
8. 保育DXでAIに任せる仕事と、人が担う仕事を分ける
9. WORLD PEACEがゲーム全体の最重要指標として機能する
10. 誕生日メッセージを最初から前面に出さず、最後に回収する
11. `npm run build` が成功する
12. READMEに起動方法、操作方法、コンテンツ追加方法を記載する

---

## 実装の進め方

一度に全機能を雑に作らず、以下の順で実装してください。

1. Phaserの起動と1280×720の画面
2. 主人公の移動と受け止めアクション
3. 4つのゲージ
4. HOLD → 選択 → BETTER PLANの基本ループ
5. チュートリアル
6. ゴリラステージ
7. 保育DXステージ
8. 教育ステージ
9. 最終ステージとエンディング
10. ビジュアル、音、演出の調整
11. 全分岐のプレイテスト

各工程後にブラウザで動作確認し、コンソールエラーを解消してから次へ進んでください。

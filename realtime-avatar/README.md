# リアルタイム リップシンク アバター 🎙️

マイクの音声にリアルタイムで反応して口パクする 2D アバターです。
ブラウザだけで動くので、Zoom や Google Meet の会議にアバターで参加できます。

（参考: https://x.com/kzkhykw/status/2077223704363405550 の「リアルタイム版」を再現したもの）

## 使い方

1. `index.html` を Chrome / Edge で開く
   - ダブルクリックで開くだけで動きます（サーバー不要）
2. 「▶ マイク開始」を押してマイクを許可する
3. 喋るとアバターが口パクします
   - 反応が弱い/強いときは「感度」を調整
   - 周囲の雑音を拾うときは「ノイズゲート」を上げる

## Zoom / Google Meet で使う

### 方法1: 画面共有（いちばん簡単）

1. `H` キーで UI を隠す
2. Meet / Zoom の「画面を共有」でこのタブ（またはウィンドウ)を選ぶ
3. 声はふつうにマイクから入るので、共有画面のアバターが口パクします

### 方法2: カメラ映像として映す（OBS 仮想カメラ）

1. [OBS Studio](https://obsproject.com/) をインストール
2. 「ソース」→「ウィンドウキャプチャ」でこのページを追加
3. 背景をグリーンにして OBS の「クロマキー」フィルタを掛ければ、好きな背景と合成できます
4. OBS の「仮想カメラ開始」を押す
5. Zoom / Meet のカメラ設定で **OBS Virtual Camera** を選択

## 自分のキャラで喋らせる

### 画像1枚だけで喋らせる（いちばん手軽）

「アバター画像」から画像を **1枚** 選ぶと、その画像に口を重ねて動かすモードになります。

1. 画像を1枚選ぶ
2. 画面上でキャラの **口の位置をクリック** して指定
3. 「口の設定」で大きさ・角度・色を微調整
   - 横顔のキャラは角度を付けるとなじみます
   - 口の色はキャラの線の色に合わせると自然です

口は喋っているときだけ描画されるので、黙っているときは元の画像のままです。
口の位置・大きさなどの設定は自動保存されます。

### 差分画像でヌルヌル動かす

画像を **複数枚** 選ぶと、口の開き差分でアニメするモードになります。

- **口を閉じた画像 → 半開き → 全開** の順（ファイル名順）になるように選択してください
  - 例: `01_close.png`, `02_half.png`, `03_open.png`
- 2枚（閉じ/開き）だけでも十分それっぽく動きます
- Notion AI や画像生成 AI で口の開きだけ違う差分画像を作ると簡単です

## 機能

- マイク音量 → 口の開き（アタック速め・リリース遅めで自然な口パク)
- スペクトル重心 → 「い・え」っぽい口の横広がり
- まばたき・呼吸のゆれ（内蔵アバター）
- グリーンバック / ブルーバック / 任意の背景色
- 配信モード（`H` キーで UI 非表示）
- 設定は localStorage に自動保存

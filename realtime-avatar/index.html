Zoom / Google Meet で使う方法 方法1: 画面共有（いちばん簡単）
  1. このページでマイクを開始し、Hキーで UI を隠す
  2. Meet / Zoom で「画面を共有」→ このタブ（またはウィンドウ）を選ぶ
  3. 声はふつうにマイクから入るので、アバターが口パクします
方法2: カメラ映像として映す（OBS）
  1. OBS Studio で「ウィンドウキャプチャ」にこのページを追加
  2. 背景を緑にしてクロマキーを掛ければ好きな背景と合成可能
  3. OBS の「仮想カメラ開始」を押す
  4. Zoom / Meet のカメラ設定で「OBS Virtual Camera」を選択
設定は自動保存されます。Hキーで UI 表示/非表示を切り替え。

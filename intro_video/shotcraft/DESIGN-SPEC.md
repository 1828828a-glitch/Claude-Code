# Opus 5 紹介動画 — 設計 spec(video-shotcraft / 自主自由創作)

制作モード: **自主自由創作**(ユーザー選択)。画面比: **横型 1920×1080 を先に作り、縦型 1080×1920 にリパック**(ユーザー選択)。
本 spec が Stage 0〜3 の判断記録であり、これをもって制作放行とする(自主自由創作では Agent が一貫性チェックののち自ら放行)。

## Stage 1: 視覚方向と動效トークン

### 選定方向: 「暗場・紙以外・活字とインクの理性」

3方向を検討し、以下を採用。理由は既存資産との整合と受众適合。

| 方向 | 判断 |
|---|---|
| A. 暗場 + Anthropic ブランド(採用) | 既に検証済みのトークンがあり、Anthropic の実ブランド。原則2「視覚言語は製品自身から生やす」を最短で満たす |
| B. 紙・インク・琥珀(Ink Press 系) | 不採用。Opus 5 の製品視覚と無関係な「宣伝片の皮」になる。原則2 違反 |
| C. 明場ミニマル白背景 | 不採用。ターミナル素材と喧嘩し、暗場でしか効かないカード(聚光/霓虹/光効)が全部死ぬ |

### 動效性格トークン

品牌→動效パラメータ表の二軸判定:

- **能量軸**: 低寄り。Anthropic は沉稳・premium・機構感。派手な過冲は品位を落とす
- **調性軸**: 中央やや厳粛。受众が非エンジニアなので冷たすぎない

→ プリセットは **「専業信頼(fintech/enterprise/B2B)」を基礎に、「平静関懐」寄りへ微調整**。

| token | 値 |
|---|---|
| 主時長 @30fps | 24f(専業信頼 21f を平静側へ +3f) |
| 入場 easing | `cubic-bezier(0, 0, 0.2, 1)` |
| 過冲 | 1.0(通常)。**ただし落地隠喻のある動作は y1 > 1 必須**(判例優先。「専業信頼は弾まない」は淡入/推移類にのみ適用) |
| squash | 0 |
| hold | 字標落定 ≥30f、批量動效収尾 15f 静止、開場主体動作弧 ≥3s |

自己チェック①: 成片の動效を三語で言うと「静か・正確・少し温かい」。ブランド語と合う。
自己チェック②: 同一トークンで入場/転場/hold を統一する。二種混用はしない。

### styleframe

**実施する**(横型は新規フォーマットのため)。純 HTML/CSS で 1920×1080 の静止3枚(開場字標 / プロフィールカード聚光 / なかまカード)を出し、Playwright で撮って字体・色・材質・情報密度を検証する。Remotion コードは書かない。

### motion breakdown(参考片の逐帧分解)

P2 の要求どおり、参考片は先にフレームまで分解して手法清単にする。全局に一律適用はしない。
抽出は `reference/study.py`(等間隔 N フレーム + contact sheet + 隣接フレーム差分量)。

> **全体の雰囲気を決める参考片は未指定。** 現時点で分解したのは、実装対象ショットの
> Gallery 参考様片のみ。雰囲気側の参考片(再現したいアニメーションの手本)が入り次第、
> 同じ手順で分解してこの表に追記し、各ショットへの採用/棄却を明記する。

#### `ai-stream-response`(SHOT 3 の参考様片 / 80フレーム・5.06s を分解)

カードの散文だけでは分からなかった時値が出た。**採用する**。

| 手法 | 参考片の実装(実測) | 取舍 |
|---|---|---|
| パネル入場 | 3D で傾いた状態から現れ、**0.15s(約4f)で平面に落ち着く**。差分量 2.4→1.3→0.7 と急減衰 | 採用。ただし本片は前ショットが字標退場なので、傾きは浅く(rotY 12°程度)して繋ぐ |
| 結論先到 | `RESULT SUMMARY` ラベル + 要約1行が **0.65s に着地**し、ほぼ即時に出る(0.65→0.71s で完成)。その後 **0.8s ひとりで hold** してから証拠行が来る | 採用。この「要約だけの空白」が結論先到の体感を作っている。要約を打字機にせず一気に出すのも実測どおり踏襲 |
| 証拠行の二段階 | 各行が **①淡いグレー + 中空(スピナー)アイコンで出現 → ②約4f後に緑のチェックへ反転し、本文と右端の数値が明るくなる**。淡出淡入ではなく**状態遷移**が見せ場 | 採用。ここが一番の発見。単なる逐条フェードインで作ると、この二段階が消えて別物になる |
| 行の間隔 | 出現ピーク 1.46 / 1.84 / 2.15 / 2.46s → 間隔 **0.37 / 0.31 / 0.31s(約11, 9, 9f)。ほぼ均等で加速しない** | 採用。R2 の「批量入場は加速」はここでは適用しない。読ませる行なので均等が正しい(カードの能量欄も「阅读优先于速度炫技」) |
| 完成態 | 2.7–3.3s に残りの行が入り、最後に全体が完成態へ収束して静止 | 採用。本片は 182f 取っているので、収尾の静止を実測より長めに確保できる |

適配時の注意: 本片の証拠行は日本語の短文3–4行にする(参考片は英語6行)。行数を減らすぶん間隔は
9f を保ち、余った尺は収尾の静止に回す。

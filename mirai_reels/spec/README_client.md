## 1. 進め方

**最優先：直近1か月分（11/19〜12/18）の R01〜R09。仕様は「直近1か月_R01-R09_制作指示.md」を見る（こちらがREADMEの5章より優先）。**


1. まず **状態が「今すぐ作れる」のリール**（R02・R03・R04・R05）を作る。写真は使わず、参考リールと同じモーショングラフィック（文字＋イラストアイコン）で作る。
   ※2026-11-18 県のご指示：写真は自治体・観光協会の公式写真を優先し、Wikimedia Commonsの写真はプレゼントキャンペーン第8弾・第7弾コメント紹介だけOK。なので、リールは原則として写真なしで作る。各仕様の「／p_○○.jpg」は使わない（公式写真が届いたら差し替えを検討）。
2. 「テンプレート」のリールは、仮の文言で枠だけ作る。答えが集まったら `reels.json` の `texts` を差し替えて再出力する。
3. 「保留」のリールは作らない（許諾・撮影・写真待ち）。
4. 1本ごとに、書き出した動画と、0秒・中盤・最後のフレームを静止画で `out/` に保存して確認できるようにする。

## 2. 書き出し仕様（全リール共通）

| 項目 | 指定 |
|---|---|
| サイズ | 1080×1920（9:16、縦） |
| 形式 | MP4（H.264、yuv420p）、30fps |
| 長さ | 15〜20秒（指定のあるものはそれに従う） |
| 音声 | **入れない（無音で書き出す）**。BGMは投稿時にInstagramアプリの音源から付ける。市販曲・フリー音源を動画に入れない |
| ファイル名 | `out/R02_20261122_冬のイルミどれが好き.mp4` の形式 |
| カバー画像 | 各リールの1枚目と同じデザインのPNG（1080×1920）を `out/R02_cover.png` として別に保存 |
| 作り方 | Python（Pillowでフレーム生成＋ffmpegで結合）でも Remotion でもよい。同じ入力から同じ動画が再現できる作りにする |

### 安全領域（Instagramの表示に隠れない範囲）
- 上 220px、下 400px、右 140px には文字を置かない（ボタン・キャプションと重なるため）。
- 大事な文字は中央 1080×1350 の範囲（y=285〜1635）に収める。プロフィールの一覧では中央の 1080×1350 だけが見えるため。

## 3. デザインのルール（参考リールに合わせる）

**見た目は reference/style_reels/ の参考リール（キッズサポーター・子育て月間、同アカウントで投稿済み）に合わせる。**

（1080×1920・30fps・60秒・無音。00_keyframes_overview.png に流れをまとめてある）

参考リールの特徴（これをまねる）
- 背景：やわらかい単色（クリーム #F6EDE2／コーラル #EE7A5C／ミント #BFE6D3／ピンク #F4D6CC など）。クリーム地に放射状のサンバースト、大きな円や水玉を背景の飾りに使う
- 文字：丸みのある極太ゴシック（M PLUS Rounded 1c Black または Zen Maru Gothic Black）。濃い茶 #4A3328、強調語だけアクセント色（コーラル・オレンジ）。キーワードの下に黄色のマーカー線や、にっこり口のような曲線
- 動き：文字が1文字ずつ・1語ずつポンと出る（0.15〜0.25秒の拡大バウンド）、吹き出しがスライドイン、アイコンがふわっと出る。小さな星・ハート・キラキラが散る。1カット2〜4秒でテンポよく切り替え
- 絵：フラットなイラストアイコン（カレンダー、スマホ、紅葉、ツリーなど）。人物は画面下からのぞく丸い顔のキャラ程度。写真は使わない
- ロゴ：県章（白い角丸の台の上）を上中央に小さく、MIRAI CANVASロゴを中央やや下に小さく。毎カット同じ位置
- 縁取り文字は白フチ程度まで。グラデーション・リアルな影・3D表現・AIっぽい写実的な絵は使わない

注意
- イラストは手で作った図形（SVG／Pillowの図形）か、フリー素材でもライセンスが明確なもの（例：Twemoji CC-BY 4.0 はクレジット要）だけ。AIで生成した絵は使わない
- 実在の施設を絵で描くときは、形を正確にまねない（「イメージ」と分かるシンプルなアイコンにとどめる）

### ロゴと表記（必ず守る）
- **県章（kenlogo.png）は支給データをそのまま使う**。描き直し・色変更・変形・AIでの生成はしない。白い帯の上に置き、周りに余白をとる。
- MIRAI CANVASロゴは小さく、クレジットとして扱う（県章より目立たせない）。
- ロゴは最初のカットと最後のカットに入れる（上の安全領域より下、y=230前後）。

### 写真のルール（公式写真などを使う場合だけ。必ず守る）
- **使ってよいのは assets/photos/ の写真だけ**。ネットから別の写真を拾わない。AIで画像を作らない。
- **写真は加工しない**：色の補正・合成・人や物を消す処理・AIでの高画質化はしない。トリミングと拡大・移動の動きだけOK。
- 写真が映っている間は、画面下（y=1480〜1510あたり、安全領域の内側）に必ずクレジットを出す：「写真：撮影者／Wikimedia Commons（ライセンス）」。文字は24px・補足文字色。
- 何の写真かも小さく書く（例：「みなとみらいの夜景」）。会場の写真でもイベント当日の写真でない場合は、その旨を書く（例：「会場のサムエル・コッキング苑（昼・2022年）」）。

### 文言のルール
- 日付は「11/27(金)」の形。開催情報の最後に「※内容は変更の場合あり。最新情報は公式サイトで確認を」を入れる。
- リンクは貼れないので、誘導は「『神奈川県 ○○』で検索」と書く。
- 最後のカットは、意見を集める呼びかけ（例：「行きたい番号をコメントで教えてね」）＋「保存しておこう」。

## 6. 納品前チェック
- [ ] 1080×1920・30fps・無音のMP4になっている
- [ ] 文字が安全領域からはみ出していない（上220／下400／右140）
- [ ] 県章は支給データそのまま。変形・色変更していない
- [ ] 写真はassets/photos/のものだけで、加工していない
- [ ] 写真が出ているカットには必ずクレジットが入っている
- [ ] 日付・曜日・時間・料金がこの指示書と一致している
- [ ] 最後のカットに、意見を集める呼びかけが入っている
- [ ] 仮の文言（テンプレート）が残っていない

# みらキャン リール R01〜R09

神奈川県 次世代育成課の Instagram「MIRAI CANVAS」に投稿するリールを、コードで書き出す仕組みです。発注元の指示書は spec/ に置いてあります。いまの作業範囲は spec/直近1か月_R01-R09_制作指示.md で、spec/README_client.md の5章より優先します。

## 書き出し

```bash
./build.sh            # R01〜R09 をすべて
./build.sh R03 R09    # 指定したものだけ
```

1本あたり、out/ に次のものができます。

- MP4：1080×1920、30fps、H.264（yuv420p）、音声なし。BGMは投稿時にアプリで付ける前提
- カバー：R01_cover.png のように、1枚目のカットが出そろったところのPNG
- 確認用の静止画：0秒、中盤、最後のコマ

ファイル名は R02_20261122_冬のイルミどれが好き.mp4 の形です。公開前に確認が要る R07 と R08 は、末尾に _確認待ち を付けて書き出します。R09 は、仮の文言のうちは _仮文言 付きの名前になります。

書き出しの前に、各カットの終わり近くで文字の位置を測り、安全領域（上220・下400・右140、大事な文字は y=285〜1635）からはみ出していないかを確かめます。はみ出しがあれば一覧を出して止まります。

## 中身の場所

- src/reel.html：ブラウザで開くと再生できる。上のプルダウンでリールを切り替え、安全領域ボタンで避ける範囲を赤く表示
- src/engine.js：カットの横スライド、見出しがポンと出る動き、アイコンがふわっと出る動き、ロゴ、安全領域のチェックなど共通の部品
- src/icons.js：イラストアイコン。すべて図形で手作りしていて、Twemoji などの外部素材は使っていない
- src/reels/R01.js〜R09.js：リールごとの中身
- spec/reels.json：18本の一覧。R09 の答えと R01 の写真はここから読む
- render.cjs：1コマずつ撮って MP4 にする

## 文言と写真の差し替え

R09 は仮の文言で枠だけ作ってあります。12/3 のストーリーズの答えが集まったら、spec/reels.json の R09 にある texts を6つ書き換え、texts_status を「確定」にして ./build.sh R09 を流します。「仮」のままだと、画面の左上に注意書きが出ます。答えが6つに足りないときも、空いた枠を埋めたうえで同じ扱いになります。

鳩サブレー缶の写真の許諾が取れたら、spec/reels.json の R01 にある photo に写真の場所とクレジットを入れて ./build.sh R01 を流します。6〜9秒のカットでプレゼント箱が写真に替わり、画面下にクレジットが入ります。写真には手を加えません。

## 作りの決まりごと

- 写真は使わない（11/18 の県のご指示）。例外は、許諾が取れたときの R01 の鳩サブレー缶だけ。ネットから拾った写真や AI で作った画像は使わない
- 県章は、県の KI デザイン利用案内に入っていた KI シンボル基本形（B-1-1）を、変形も色替えもせずに白い台の上に置いている。全カットの上中央に出す。支給の kenlogo.png と違う場合は、assets/logos/ki_symbol_b-1-1.png を、名前はそのままで kenlogo.png の絵に置き換える
- MIRAI CANVAS ロゴは最初と最後のカットだけ、小さく出す
- 書体は Zen Maru Gothic（OFL）。リポジトリには入れず、fetch_fonts.sh が Google Fonts から取ってくる
- アニメーションは GSAP 3.12.5 を vendor/ に置いて使う。一度書体を取ってきたあとは、ネットにつながなくても同じ動画が書き出せる
- 効果音は入れないが、音を付けるときの目安として、ポンやスライドの時刻を build/Rxx_cues.json に残している

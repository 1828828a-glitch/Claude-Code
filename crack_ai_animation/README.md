# crack AI事業アップデート計画 60秒アニメーション

行動規範③「自分の持ち場から会社を更新する」と④「他者が前へ進める場をつくる」を、60秒で伝えるモーションインフォグラフィックです。動画生成AIは使わず、HTML・CSS・JavaScript・SVGだけで動かしています。文言も秒数もあとから直せます。

## 見る

index.html を Chrome か Edge で開くと自動で再生が始まります。1920×1080 で設計していて、ウィンドウに合わせて16:9のまま縮みます。

| 操作 | キーとボタン |
| --- | --- |
| 再生と一時停止 | Space、または左下の再生ボタン |
| 最初から | R、または「最初から」 |
| 1秒戻る、進む | ← →（Shift を押しながらで5秒） |
| 操作UIを隠す | H、または「UIを隠す」 |
| 好きな位置へ移動 | 左下のシークバー |

URLの末尾に ?record=1 を付けるとUIを隠した状態で始まり、?t=38 を付けると38秒から再生します。index.html?record=1&t=38 のように組み合わせられます。再生中にマウスを2.5秒動かさないと、UIは自動で薄く消えます。

## シーン構成

| 秒 | 章 | 画面で起きること |
| --- | --- | --- |
| 0–6 | 現状 | 研修会場と講師と顧客にチェックが付く。そのあいだに工藤の頭上へ案件カードが8枚積み上がり、体が少しずつ沈む |
| 6–14 | 課題 | 顧客→代理店→代理店→crack の矢印が細くなり、関係と知見の粒は代理店を通るたびに消える。研修・導入・開発はばらばらに揺れ、グラフでは案件数だけが伸びる |
| 14–21 | 転換 | 画面が中心に吸い込まれてリセット。crack を中心に波紋が広がり、AI研修→人材育成→定着支援→AI導入→開発が円でつながる |
| 21–29 | 行動規範 | ①発見→②価値化→③更新が並び、④の帯が下から伸びて支える。③と④に「今回の主軸」 |
| 29–38 | 一気通貫 | 研修だけを囲んでいた括弧が、直営業から内製化・次の提案までを一本の線で包む |
| 38–47 | 役割移管 | 見せ場。工藤の頭上の仕事カード4枚が役割カード7枚に分かれてメンバーへ飛ぶ。受け取った人から色が付き、工藤の負荷ゲージが100%から30%へ下がる。最後に④の床が点灯する |
| 47–54 | 手段と目的 | AI、仲間、公的支援制度が顧客の課題へ合流し、顧客が前へ進む矢印が伸びる。「補助金ありきではない」は小さく添えるだけ |
| 54–60 | これから | チームが④の床の上を前へ進み、③×④、crack ロゴとラストコピーで終わる |

## 直したいとき

index.html の script 冒頭に「▼編集ポイント」としてまとめています。

- CAPTIONS は字幕の秒と文言です。`<em class="c3">` で囲むと③のオレンジ、`<em class="c4">` で④のネイビーになります。18字前後に収めると1行に入ります。
- SCENES は各シーンの開始秒と終了秒、左上の章ラベルです。シーン内の動きはシーン開始からの相対秒で書いているので、開始秒をずらすと中身ごと移動します。
- TEAM はメンバーの名前、役割、服の色、どの仕事カードから受け取るかです。横位置は240px間隔の7人前提なので、人数を変えるときは buildDOM() の `m.x = 240 + i * 240` も合わせて直してください。
- BURDENS は工藤が手放す仕事カード、CASES は冒頭で積み上がる案件カードです。
- 色は style 冒頭の :root にあります。
- ロゴは Poppins で組んだ仮のワードマークです。正式ロゴにするなら `#s8-logo` の中身を `<img src="logo.svg" alt="crack">` に置き換えます。
- ラストコピーは `#s8-copy1` と `#s8-copy2` です。

## 動画にする

### Playwright で書き出す（おすすめ）

1コマずつ描いては撮るので、PCが重くてもコマ落ちしません。Node.js 18 以上と ffmpeg が要ります。

```bash
cd crack_ai_animation
npm install
npx playwright install chromium
npm run export        # crack_ai_update.mp4（1920×1080、30fps、60秒）
```

| やりたいこと | コマンド |
| --- | --- |
| 60fps で書き出す | `npm run export:60fps` |
| 38〜47秒だけ | `node export/render.js --from 38 --to 47 --out highlight.mp4` |
| ffmpeg がない | `node export/render.js --frames frames`（PNG連番を保存し、MP4化のコマンドを表示） |
| ffmpeg の場所を指定 | `--ffmpeg /path/to/ffmpeg` か環境変数 FFMPEG_PATH |

開発環境では1800コマの書き出しに約4分かかりました。

### ブラウザの録画ボタン（MediaRecorder）

Chrome か Edge で左下の「録画」を押し、共有ダイアログで「このタブ」を選びます。UIが消えて頭から再生され、60秒後に crack_ai_update.webm が保存されます。Region Capture に対応したブラウザでは、ステージ部分だけを切り抜いて録ります。実時間で録るので、PCが重いとコマが落ちることがあります。MediaRecorder の WebM は長さの情報を持たず、プレイヤーによってはシークしにくいので、MP4 に変換しておくと扱いやすくなります。

```bash
ffmpeg -i crack_ai_update.webm -c:v libx264 -pix_fmt yuv420p -crf 18 crack_ai_update.mp4
```

### 画面録画

index.html?record=1 を開いてフルスクリーンにします（Windows は F11、macOS は ⌃⌘F）。macOS なら ⇧⌘5、Windows なら Win+Alt+R か OBS で録画を始め、R キーで頭から再生します。16:9 のディスプレイなら上下左右に余白が出ません。

## 音を付けるときの目安

音声は入れていません。編集ソフトでBGMとSEを付けるときは、画面の動きに合わせた次の秒数が使えます。音の案は台本の指定です。

| 秒 | 画面の動き | 音の案 |
| --- | --- | --- |
| 1.70〜4.92（0.46秒おき） | 案件カードが積み上がる | カッ |
| 7.3、8.0、8.7 | 商流の矢印が伸びきる | 短いクリック |
| 14.1 | 画面リセット、crack が出る | ここからビートを入れる |
| 14.9〜17.5 | 円が順につながる | シュッ |
| 30.1〜34.1 | 一本の線がノードに届く | シュッ |
| 38.35〜38.80 | 工藤に仕事カードが落ちる | カッ |
| 41.45〜43.97（0.42秒おき） | 役割カードがメンバーに届く | ポン |
| 44.0 | ④の床が点灯 | 余韻の入り |
| 50.4〜50.8 | AI・仲間・制度が合流 | 軽いデジタル音 |
| 56.6 | ロゴ | 短い上昇音 |

## 台本のチェック項目について

- 60秒で最後まで再生されるか。実時間で流して60.1秒で終端に止まることを確認しています。
- シーン秒と台本の一致。SCENES 配列が台本の区切りそのものです。
- 日本語が画面外に出ていないか。0.1秒刻みで全要素の位置を調べ、文字のはみ出しはありませんでした。画面外から飛び込んでくるカードだけが登場の一瞬だけ外にいます。
- 38–47秒の印象。カードの飛行、受け取った瞬間のリング、色の点灯、負荷ゲージ、④の床の点灯をこの9秒に集めています。
- ③と④の意味。③はオレンジ、④はネイビーで全編そろえています。④は21秒で土台の帯として現れ、そのまま一気通貫の床になり、役割移管では人がその上に立ちます。
- UIの非表示。H キー、?record=1、無操作2.5秒の自動非表示のどれでも消えます。

## ファイル

- index.html は本体です。1ファイルで完結していて、外から読むのは Google Fonts だけです。オフラインでも端末の日本語フォントで動きます。
- export/render.js は MP4 の書き出しスクリプトです。
- package.json は書き出し用の依存（playwright）です。

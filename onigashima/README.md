# 鬼ヶ島たんけん — Onigashima 3D

Three.js で作った、リアルタイムで鬼ヶ島を探検して遊べる 3D Web サイトです。
ビルド不要・完全自己完結(three.js は `vendor/` に同梱)なので、`index.html` を
ブラウザで開くか、任意の静的サーバーで配信するだけで動きます。

## 遊び方

```bash
cd onigashima
python -m http.server 8000
# → http://localhost:8000 を開く
```

- **WASD / 矢印キー** — 移動(**Shift** でダッシュ)
- **マウスドラッグ** — カメラ回転
- **Space / クリック** — 刀で攻撃
- **🌙/☀️ ボタン** — 昼と夜の切り替え
- スマホ・タブレットは仮想スティック+攻撃ボタンで操作できます

**目標:** 島にひそむ **鬼を 6 匹** 退治して、**きびだんごを 8 個** あつめよう!

## 見どころ

- プロシージャル生成の島(浜辺・草原・中央の岩山)と揺れる海
- 鳥居・鬼の砦の門・桟橋・桜と松の木・岩
- 徘徊し、近づくと追いかけてくる赤鬼・青鬼
- 撃破パーティクル、焚き火の火の粉、提灯のゆらめく灯り(夜)
- 昼夜の切り替え(空・霧・光がなめらかに変化)
- WebAudio による手作り効果音(斬撃・撃破・収集・クリアファンファーレ)

## 技術メモ

- Three.js r160(ES Modules + importmap、`vendor/three.module.js` に同梱)
- 地形は fbm ノイズ + 放射状の減衰で生成し、標高で頂点カラーを塗り分け
- 影付きディレクショナルライト+環境光、夜はポイントライト(提灯・焚き火)
- 依存パッケージ・ビルド工程なし(単一 HTML + 同梱 three.js)

# フリオチLAB

フリオチ思考訓練ドリルの最小実用版。設計書「フリオチ思考訓練ドリル 設計書」と研究資料「フリオチの構造と実例大全」をもとに作っている。

正解のボケを当てるゲームではない。相手の予測を読み、同じ尺度の上で理解できるズレを作り、短く着地させる思考回路を育てるための練習ツール。

## 起動

```bash
pip install -r requirements.txt
streamlit run furiochi_app.py        # Web版（スマホ表示を想定）
python -m furiochi_lab               # ターミナル版：今日の10分
python -m furiochi_lab --mode M02    # モード指定
python -m furiochi_lab --list        # 問題バンク一覧
```

AI講評を使うときは `ANTHROPIC_API_KEY` を設定する（`ant auth login` のプロファイルでもよい）。未設定なら、出題側の設計意図と成立例を見ながら自己採点で進む。

| 環境変数 | 内容 | 既定値 |
| --- | --- | --- |
| `FURIOCHI_DATA_DIR` | 学習履歴の保存先 | `~/.furiochi_lab` |
| `FURIOCHI_AI` | `off` でAI講評を使わない | 有効 |
| `FURIOCHI_MODEL` | 講評に使うモデル | `claude-opus-5-5` |
| `FURIOCHI_EFFORT` | 講評の思考量 | `medium` |

## Web版（claude.ai）

`furiochi_lab/web/src/` は claude.ai 上で開く1ページ版の部品（shell.html・CSS・JS）。問題バンク・採点ルール・AIプロンプトは Python 側から書き出して埋め込むので、問題を直したら作り直す。

```bash
python furiochi_lab/web/build.py furiochi-lab.html
```

AI講評は閲覧者自身の Claude で行い、使えないときは自己採点に切り替わる。履歴は閲覧者ごとの非公開領域に保存し、書けないときはそのブラウザに保存する。

効果音は寄席の鳴りもの。練習を始めると出囃子、問題が出るとめくりの音、回答を送ると拍子木（M07 はハリセン）、結果は得点率に応じて太鼓と拍手、30秒チャレンジは残り5秒から刻みと時間切れの鉦が鳴る。どれも Web Audio で合成していて、見出し右のスピーカーで消せる。Audio Studio などで作った音声を `furiochi_lab/web/sounds/` に置いてビルドすると差し替わる（手順とプロンプトは `sounds/README.md`）。

## 実装した範囲

設計書の「次の一手」にある4モードと Day 1 で使う M03 に、拡張段階の M04・M07 を加えた7モード。7日間パイロットの Day 1〜5 はすべてのメニューがそろう。

| モード | 問題数 | 採点 |
| --- | --- | --- |
| M01 フリ→オチ | 10 | 5軸10点 |
| M02 オチ→フリ | 10 | 5軸10点 |
| M03 期待の言語化 | 8 | 予測の具体性・フリとの対応の2軸4点 |
| M04 同一フリ3オチ | 8 | 型の使い分け・各案の成立・理解の速さ・コンパクトさの4軸8点（指定の3つの型で1案ずつ、各40字目安） |
| M05 フリオチ自作 | 8 | 5軸10点（型の指定あり） |
| M06 ネタの修理 | 8 | 診断＋改善版を5軸10点 |
| M07 ツッコミ設計 | 10 | ズレの指摘・基準の提示・短さ・言い方の4軸8点（Bとして返す一言、30字目安） |

設計書7章のサンプル問題（M04 の D01、M07 の T01〜T04 を含む）に、弱点タグごとの修理問題などを足して計62問。AIが使えるときは同じ形式の問題を生成できる。

学習ループは、出題、回答、狙った期待とズレの自己記述、講評、成立例と別案、同じお題での再挑戦、弱点タグの蓄積の順。講評は設計書6章の順序（期待、ズレ、内訳、改善最大2つと修正案1つ、別案）で出す。安全性は点数に混ぜず別枠で判定する。

ホームには今日の10分（直近の弱点タグに効くモードを優先）、連続学習日数、7日間パイロット、Lv1・Lv2の進行判定（仮説）を置いた。回答ごとに制作時間（問題を出してから回答を送るまで）を記録し、結果画面で自己満足度（1〜5、任意）を残せる。マイノートではお気に入り・実演メモ・JSON書き出しができ、制作時間の中央値と自己満足度の平均も見られる。型の辞典には12の基本型、20技法、国内外28作品の構造分析を収録した。
